# Com4nent - 프로젝트 2: 한국경제 메인 랜딩 페이지 개선

프로젝트 기반 UXUI 디자인 실전 캠프 5기 팀 프로젝트 레포지토리입니다.

## 팀 소개

- **팀명:** Com4nent (컴4넌트) — 팀원 4명의 의미를 담아 확정
- **팀 구성:** 팀원 4명, 강사/멘토 1명

## 프로젝트 개요

- **주제:** 한국경제 메인 랜딩 페이지 개선
- **선정 이유:** 특정 타깃에 국한된 섹션보다 첫 화면인 랜딩 페이지를 개선하는 것이 설계 범위가 넓고 도전 가치가 크다고 판단
- **주요 아이데이션**
  - 정보 과부하 해소 및 카테고리 분류 체계 정리
  - 사용자 유형별 진입 경로 최적화 (자동 추천 섹터 배치, 피드 분기 플로우)
  - AI 활용 문단별 요약 모드 도입 검토
  - 광고 영역 처리 방식 개선 논의

## 협업 방식

| 분류           | 채널                  | 용도                                |
| -------------- | --------------------- | ----------------------------------- |
| 일반/급한 연락 | 카카오톡 (오픈채팅방) | 실시간 알림, 간단한 소통            |
| 프로젝트/작업  | 디스코드 (Discord)    | 화면 공유, 음성 회의, 자료 아카이빙 |
| 과정 공식 소통 | LMS 과정 채팅방       | 공식 기록 보존                      |
| 코드/문서 관리 | GitHub                | 프로젝트 1, 2 레포지토리 분리 운영  |

- 의견 불일치 시 다수결 원칙, 동률 시 캐주얼 결정 → 팀장 조율 → 강사 중재 순으로 진행
- 회의록은 AI 회의록 툴로 요약본을 추출하여 `MeetingNotes/` 폴더에 기록

## 폴더 구조

```
MeetingNotes/   # 회의록 및 프로젝트 계획서
```
