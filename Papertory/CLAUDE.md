## 제품 개요 (PRD)

- **제품명:** 페이퍼토리 — 한국경제 뉴스 모바일 앱

### 1. 제품 개요
- **문제 정의:** 종이신문이 주던 "몰입감 있는 열람"과 "기록·복기 습관"을 디지털이 재현 못함 — ① 로딩 지연·페이월·팝업·어려운 용어로 입문자가 완독 전 이탈, ② 기록·재방문 장치 부재로 소비가 일회성에 그침, ③ 무한스크롤+배너광고로 에디토리얼 지면 몰입감 상실. 핵심 한 줄: 읽어도 기록·루틴으로 안 이어져 콘텐츠 자산이 재방문·구독으로 전환되지 못함
- **목표:** 종이신문급 몰입 열람 경험을 모바일에 재현하고, 읽기·기록을 일상 루틴화해 재방문율·완독률을 높임 — 2030 대상, 형광펜 스크랩·완독도장 등 기록 행위에 리워드 연결(캐릭터 육성형이 아닌 "기록 루틴" 습관화가 핵심), 출석·기록 기반 리워드(디지털 수첩, 스티커·마스킹테이프)로 루틴 강화
- **차별화 포인트:** ① 에디토리얼 디자인(메인기사 1 + 스택 카드, 광고 최소화)으로 지면 몰입감 재현 — 페이지 넘김 손맛·질감은 부차 요소, ② 읽기→형광펜/클리핑→다이어리형 스크랩까지 원스톱 "읽기→기록→아카이빙", ③ 기록을 장려해 꾸준한 열독을 만드는 "경제공부의 기준" 제시(나만의 학습 아카이브), ④ 출석·기록 → 포인트·스티커·잠금해제 보상 + 스크랩 공유 커뮤니티·스티커 상점, ⑤ 소장 욕구 자극 감성 UI + SNS 인증·공유
- **트렌드 반영:** 아날로그·뉴트로(종이신문·다꾸), 기록/아카이빙 앱 부상(노션류), AI 요약 소비, 챌린지형 리텐션(네이버 주간일기류), 소장·인증 문화(굿즈·인증샷)

### 2. 사용자 정의
- **핵심 타깃:** 경제적 성장 지향형 자기계발자(2030) — 경제 뉴스를 커리어·자산 성장의 무기로 삼으려는 고관여 입문층. Pain: ①경제 흐름 뒤처짐 불안 ②기존 경제지의 불친절한 용어·UI로 입문 실패 반복. Desire: 읽고 흘리지 않고 기록·아카이빙해 자산화(포트폴리오)하는 경험
- **대표 페르소나:** 송소라(32·여·서울 강동구, 교육·훈련 사무원) — 인재개발팀장이 목표, 경제·경영서 탐독 + 분기별 성과 기록하는 "정리의 달인", 카페 다이어리 정리가 습관
- **사용자 시나리오 (3단계):** ① ENTER — 지면식 레이아웃·감성 UI로 첫 기사 완독 성공 → ② ARCHIVE — 형광펜·메모 → "나만의 책장"에 자동 아카이빙, 책이 두꺼워지며 성장 체감(루틴 형성) → ③ SHARE — 스티커로 스크랩 꾸며 SNS 인증(#직장인공부 #공스타그램), 딥링크로 지인 유입 → 오가닉 확산
- **가치 정의:** 지면형 레이아웃으로 피로도 감소 → 형광펜·스티커 기록 습관화로 재방문·체류시간 증가 → 자동 아카이빙이 학습 포트폴리오가 되어 완독률·효능감 상승 → 출석/기록 리워드(루틴 강화, 캐릭터 성장 아님)로 지속 사용 동기

### 3. 기능 정의
- **필수 기능:** 지면 디지털 재현(에디토리얼 레이아웃, 단순 인터페이스), 형광펜·클리핑 스크랩(리소스화·자동 아카이빙·SNS 공유), 경제공부 루틴화 리워드(디지털 수첩, 출석 보상), 스크랩 모아보기(책장)
- **선택 기능:** 페이지 넘김 손맛·소리·질감 등 아날로그 감각 요소. [보류] 다마고치형 캐릭터 육성 게임 — 리소스 대비 효율 재검토 필요
- **우선순위**
  - **P0(MVP):** 오늘의 지면(메인 1 + 스택 카드), 기사 원문 뷰어 + AI 요약, 형광펜·클리핑 리소스화, 리소스 꾸미기(노트+바텀시트), 스크랩 모아보기(책장)
  - **P1(중요):** 게이미피케이션 보상 체계(출석·기록 포인트·스티커, 스티커 상점, 스크랩 공유 커뮤니티, SNS 공유 카드+딥링크 재유입), 인라인 AI 카드(이해관계자 요약·AI Q&A·쉽게읽기 슬라이더), 내 지갑 번역기(용어·수치를 "내 자산 관점"으로 풀이)
  - **P2(후순위/보류):** 페이지 넘김 손맛 재현, 달력형 모아보기(기준 미정), 캐릭터 육성(보류), 방송기사 모아보기 등

### 4. 데이터 및 기술 정의
- **데이터 수집:** 기사 원문·메타(카테고리·발행일·기자·인용·수치)는 한경 CMS/API에서 문단 단위로 구조화 수집(한경 제공 전제). 사용자 행동 로그(스크롤·완독, 형광펜·클리핑, 스크랩 생성, 출석, 포인트, 공유) 이벤트 수집 — 스크랩(라이브러리)과 읽음 기록(달력)은 별도 엔티티. 개인화는 자산 연동이 아닌 관심사 태그(예: 부동산 전세, 미국주식) 저장. UGC(공유 카드·커뮤니티 게시글)
- **데이터 처리:** AI 콘텐츠는 기사 발행 시 **사전 배치·캐싱**(실시간 아님) — 전체 요약, 인라인 요약, 이해관계자 카드, 내 지갑 번역기, 쉬운말 버전을 미리 생성, 원문 근거 문장 동봉해 사실성 확보. **AI Q&A만 실시간**(RAG, 원문 근거) — 무료는 일일 횟수 제한 / 유료는 무제한(구독 전환 유도). 완독 판정 기준(원문 스크롤 완독 vs 스크랩 생성)은 **미정**. 게이미피케이션은 2트랙(책 두께=경험치, 포인트=재화), 스크랩 대표색 추출→AI로 책 표지 자동 생성
- **기술 스택:** 프론트(모바일) — 제스처(형광펜·바텀시트·꾸미기 캔버스) 중심, 네이티브(React Native/Flutter) 또는 PWA. AI — Claude API 권장(요약·카드·번역기·쉬운말은 배치, Q&A는 실시간 RAG), 책 표지는 이미지 생성 모델, 바이오닉 리딩은 클라이언트 처리(AI 불필요). 백엔드 — 기사/사용자/스크랩/포인트 DB, 이벤트 로깅, AI 결과 캐시. 딥링크 — Branch/Firebase Dynamic Links류(미설치 시 스토어 경유 후 원 화면 복귀). 공유 카드 — 서버 렌더 또는 클라이언트 캔버스 export. **구성 원칙: 데이터 계약(스키마)을 먼저 고정 → 개발은 목업 JSON, 시연은 실제 캐시로 소스만 교체**
- **제약 사항:** AI 비용·지연(배치·캐싱 + 실시간은 티어 제한으로 대응), 외부 LLM 연동 실패 대비 재시도/대체 처리 필요(과거 Grok 연동 실패 이슈 반영, 안정적 제공사 선택), 인용·수치는 원문 근거 문장으로 검증, 한경 기사·이미지 사용 권한 범위, 행동 로그·관심사 태그 수집 동의, 개발 단계는 목업 허용하되 시연은 실연동 필수

### 5. 사용자 경험(UX/UI)
- **핵심 화면:** ① 오늘의 지면(홈) — 메인기사 1개 + 하위 스택 카드. ② 기사 원문 뷰어 — AI 요약 토글, AI 패널(이해관계자 요약·Q&A), 내 지갑 번역기, 형광펜, 클리핑→리소스 저장. ③ 리소스 꾸미기(노트) — 다이어리형 캔버스 + 하단 바텀시트로 리소스·스티커 배치. ④ 모아보기(책장) — 꾸민 노트가 책으로 쌓여 "나만의 서재"(달력형 뷰는 기준 미정, 보류). ⑤ 리워드·상점·커뮤니티 — 출석·기록 보상, 스티커 상점, 스크랩 공유 커뮤니티, 공유 카드 내보내기. ※ 읽음/완독 판정 기준(원문 열람 vs 스크랩 생성)은 미정 — §4와 동일 이슈
- **사용성 차별화:** 에디토리얼 레이아웃으로 정보 위계·낮은 광고 피로도, 형광펜·클리핑·꾸미기는 제스처+바텀시트로 직관 조작, AI 요약·용어 풀이로 입문 장벽 완화, 단순 UI로 로딩·팝업 이탈 최소화, 소장욕 자극 비주얼+인증·공유 동선
- **오류 처리:** 로딩 지연 → 스켈레톤 UI + 오프라인 시 마지막 지면 캐시 표시(빈 화면 이탈 방지). 원문 로드 실패 → 재시도 안내 또는 AI 요약 우선 표시. 페이월/로그인 → 비로그인 열람 범위 제공, 팝업 최소·지연 노출. 클리핑·꾸미기 저장 실패 → 임시저장·자동복구. 빈 상태(스크랩·책장 없음) → 온보딩+예시로 행동 유도. 개인화 설정 전 → 기본 편집 지면·기본 카테고리 제공 + 개인화 유도 안내

### 6. 성과 측정과 성공 기준
- **리텐션:** D1/D7/D30 재방문율, DAU·WAU·MAU, 연속 출석일수

- **기록 활동:** 형광펜·클리핑 수, 리소스화 수, 노트 생성 수, 책장 성장량
- **게이미피케이션:** 포인트 적립·소진량, 스티커 상점 구매 수, 커뮤니티 공유·반응 수
- **공유·재유입:** 공유 카드 생성·클릭 수, 딥링크 재유입·신규 유입 수

## 디자인 시스템

> 전체 스펙: guidelines/design.md (Figma "디자인 시스템 + UI 통합본" 페이지 기준, 작성자: 김아영)

- **구조:** Primitive → Semantic 2단 토큰 체계. **Primitive 색상은 컴포넌트에 직접 사용 금지** — 항상 Semantic Token(`brand/primary`, `text/primary` 등)을 통해서만 참조
- **브랜드 컬러:** Primary Blue(`primary/500 #6083F5`) + Secondary Lime(`lime/200 #E6F997`) 투톤
  - 선정 배경: Blue는 한국경제라는 경제지 브랜드가 가져야 할 **신뢰감·전문성**을 담당 — CTA·브랜드 강조·데이터 시각화(읽기 기록 히트맵) 전반의 기본색. Lime은 제품의 핵심 기능인 **형광펜 하이라이트 그 자체를 상징하는 색**으로 선택됨 — 실제 형광펜/하이라이트 틴트에 lime/200 계열을 그대로 사용해, "기록하는 행위"가 브랜드 포인트 컬러와 시각적으로 직결되도록 설계. 안정적인 Blue(신뢰)와 발랄한 Lime(형광펜·2030 타겟의 경쾌함)의 대비로 "신뢰할 수 있는 경제지 콘텐츠 + 즐겁게 기록하는 습관"이라는 제품 포지셔닝을 컬러만으로 전달
- **폰트:** Primary `Paperlogy`(제목·뱃지·날짜·네비게이션, Medium/SemiBold/Bold/ExtraBold) + Secondary `Open Sans`(본문, Regular/Bold). 두 계열 혼용 금지 — 제목류에 Open Sans, 본문에 Paperlogy 쓰지 않음
  - 선정 배경: 헤드라인·UI에는 **Paperlogy**를 써서 서체 이름 자체가 갖는 "Paper(지면)" 정체성을 제품명 '페이퍼토리' 및 종이신문 재현 컨셉과 맞춤 — 굵은 웨이트가 신문 마스트헤드·헤드라인이 주는 각진 존재감과 편집 위계를 재현. 본문에는 장문 가독성이 검증된 국제 표준 산세리프 **Open Sans**를 써서 긴 기사를 오래 읽어도 눈 피로도가 낮도록 하고, PRD의 완독률 목표(자간 -2%, indent 8px로 지면처럼 읽히는 문단 리듬 유지)를 뒷받침
  - 이전에 검토되던 Pretendard 전면 통일안은 **폐기됨** — Paperlogy + Open Sans 조합이 최종 확정 스펙
- **본문 규칙:** Body 1/2는 자간 -2%, `text-indent: 8px` 필수 적용
- **레이아웃 기준:** 화면 폭 393px(iPhone 14 Pro), 카드 내부 패딩 16px, 카드 섹션 간 20px
- **Radius:** sm 12px(카드) / lg 24px(칩·pill) / xl 36px(바텀시트) / full 999px(원형)
- **아이콘:** Lucide Icon Library 사용, 디자인 시스템과 동일한 이름의 Lucide 아이콘 그대로 매칭 (커스텀은 토리 마스코트 등 예외적인 경우만)
- **상태바:** 디자인 토큰 미적용 — iOS 기본 스타일 그대로 사용
- design.md는 새 컴포넌트/스타일 결정이 생길 때마다 갱신 (변경 이력 섹션에 기록)
