AI 고도화 및 추가 기능

열독자와 입문자 두 유형을 모두 고려한 POC 설계 방향 확정
스프린트1 완료 및 다음 단계 준비
- 오후 멘토링
1.인터넷 구조
1-1. 서버 및 트래픽 관리
인터넷 구조에서 서버는 웹 서버, DB 서버로 나뉨
웹 서버는 사양이 저렴해 비용이 싸고, DB 서버는 비용이 비쌈
사용자는 인터넷 브라우저를 통해 DB에 접근함
DB에 접근할 때 개인화된 페이지를 제공하면 성능 향상 가능
인터넷 브라우저에서 개인화된 페이지를 제공하는 방안을 고려해 볼 수 있음
1-2. 초개인화
초개인화는 사용자가 예측할 만한 것만 제공하는 것
구글은 아직까지 초개인화를 잘 적용하지 못함
초개인화를 위한 키워드를 찾아보길 추천함
1-3. 유입 경로 분석
유튜브 통한 유입이 적지만, 유튜브 채널과 조회, 구독 등 다양한 경로 존재
 유튜브 방송을 보기 위해 댓글을 통해 기사를 끌어내는 방안 제안
모닝 루틴의 경우, 방송 기사 중 몇 개를 댓글에 안내하는 방안을 생각해 볼 수 있음
댓글에 기사를 제공하지 않는 이유를 분석하고, 해당 기능을 개선할 필요가 있음
2. 유입 유도
2-1. 유입 유도를 위한 전략
기사 유입을 늘리려면 유튜브 페이지에 기사 목록을 달아놓고, 이를 동영상으로 연결하자는 아이디어가 있음
기사별로 동영상에 연결되도록 링크를 달아놓으면, 유입자가 기사를 클릭하면 동영상으로 연결됨
이 방법은 디지털 기술의 한계로 인해 더 효율적인 방법이 될 수 있음
 특정 기사들을 찾아내고, 그 콘셉트를 만들면 유튜브 페이지에 기사 목록을 달 수 있음
 이 콘셉트를 통해 유튜브 페이지에 기사 목록을 보여주면, 기사 클릭 시 동영상으로 연결할 수 있음
2-2. 기사 유입을 위한 URL 분석
현재 유튜브 페이지에서 기사 유입을 위해 URL 분석을 하는 것은 중요하지 않음
디지털 기술의 한계로 인해, URL을 분석해 기사 목록을 만들 수 있는 프로그램이 없음
그러나, 기사별로 다른 동영상을 분석해 목록을 만들 수 있는 프로그램을 만들 수 있음
이 프로그램을 통해 기사 목록을 만들고, 이를 유튜브 페이지에 배치할 수 있음
이렇게 하면, 기사 클릭 시 동영상으로 연결할 수 있음
2-3. 쿠키 데이터 활용
쿠키 데이터를 통해 공부하는 사람과 공부하지 않는 사람을 나눌 수 있음
 이를 통해, 공부하는 사람에게는 공부 관련 콘텐츠를, 공부하지 않는 사람에게는 소비 관련 콘텐츠를 추천할 수 있음
 이렇게 하면, 쿠키 데이터를 기반으로 유입자에게 맞춤형 콘텐츠를 제공할 수 있음
 쿠키 데이터를 분석해 유입 경로를 찾으면, 유입 경로를 잘 보여줄 수 있음
SNS, 인스타그램, 페이스북 등의 경로를 찾을 수 있음
3. 콘텐츠가치론
3-1. 콘텐츠가치론과 활용
 인플루언서가 될 수 있고, 상업적으로도 수익화할 수 있음
 조회수, 리트윗, 라이크 수를 분석하여 검색 효과를 예측할 수 있음
 제휴 모델을 만들거나, 쉽게 링크를 달 수 있는 장치를 개발할 수 있음
환경 뉴스나 경제 대사에 대한 콘텐츠를 만들 수 있음
 서포터스 대학생의 개인 계발 측면을 반영한 콘텐츠를 만들 수 있음
3-2. 사례 분석
 경제 뉴스를 통해 조회수가 100만이 넘고, 링크가 직접적으로 달리는 사례를 찾을 수 있음
 한국경제 본 사이트 기사에 유입된 사례를 통해 인플루언서의 중요성을 알 수 있음
라이크 수와 리트윗 수를 분석하여 직접적인 연결고리를 찾을 수 있음
라이크 수와 리트윗 수를 기준으로 인플루언서의 활성화 가능성을 예측할 수 있음
직접적인 연결고리가 없어도 인플루언서가 존재할 수 있음을 보여줌
