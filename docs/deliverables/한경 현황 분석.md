# 한경 현황 분석 — 지면과의 차이점

> 출처: FigJam 보드 [project 2] Group act > "한경 현황 - 지면과의 차이점" 섹션 (node-id 186:2160, 작성 이주희)

한국경제 뉴스를 접할 수 있는 네 가지 매체 — **한국경제 웹(PC)**, **모바일한경 앱**, **한국경제 앱**, **지면(종이신문)** — 를 스크린샷으로 나란히 비교하며 매체별 지면 재현 여부, 광고배너 유무, 개별 UX 문제를 기록한 리서치입니다.

## 매체별 현황 비교

| 매체 | 지면 레이아웃 재현 | 광고배너 | 모바일 반응형 |
|---|---|---|---|
| 한국경제 웹 (PC) | X | O | X |
| 모바일한경 앱 | O | X | - |
| 한국경제 앱 | X | X | - |
| 지면(종이신문) | 원본 | 있음(빈도 낮음) | 해당 없음 |

## 매체별 상세

### 한국경제 웹 (PC)
모바일 반응형이 없고, 지면 레이아웃도 재현하지 않지만 광고배너는 붙어 있는 버전. PC 전용 스크롤 스크린샷으로 전체 페이지 구조를 기록.

### 모바일한경 앱 (지면 O / 광고배너 X)
종이신문 지면을 그대로 모바일에 옮긴 버전으로, 아래와 같은 문제가 다수 발견됨.

- **학습 기능 한계**: 스크랩을 해야만 메모가 가능한 구조로, 메모 UI 자체가 올드함. 무료회원은 기사를 끝까지 볼 수 없고 별도로 로그인 화면으로 이탈해야 해서 읽기 흐름이 끊김. 형광펜 기능이 없고, 사전(단어 뜻 찾기) 기능도 동작하지 않음.
- **탈출 동선 문제**: 지면 화면에서 나가는 버튼이 따로 없고 반드시 홈 버튼을 눌러야 나갈 수 있음. "여기서도 볼 수 있는" 뉴스 이미지를 누르고 홈 버튼을 눌러야만 지면 화면을 벗어날 수 있는 등 개선 의지가 안 보이는 불편한 동선.
- **과도한 구독 유도 & UI 노이즈**: 한경 프리미엄9 옆에 홈/소개 버튼이 두 개 다 있어야 하는지 의문(탭에도 이미 있음). 한경 프리미엄 구독 제안이 반복적으로 노출되어 "돈독 오른" 느낌을 줌. 폰트 크기 종류가 지나치게 많아, 안 그래도 정보량이 많은 뉴스앱을 더 복잡하게 만듦.

### 한국경제 앱 (지면 X / 광고배너 X)
지면도, 광고배너도 없는 별도 앱 버전.

- 스크랩 기능은 있으나 메모 기능은 없음.
- 모바일한경보다는 트렌디한 구조.

### 지면(종이신문)
- 가독성이 실제로 높은 것인지는 확신할 수 없음. 지면과 디지털의 진짜 차이는 (1) 기사 내용이 더 많이 들어간다는 점, (2) 광고 위치·개수가 산발적이지 않다는 점 정도.
- 형광펜을 치는 습관도 "지면이라서 좋아서"가 아니라, 모바일한경이 애초에 공부하기 좋은 환경이 아니고, 종이로 보면서 동시에 모바일로 검색·사진찍기 등 다른 활동을 병행해야 하기 때문일 가능성도 있음.

## 웹 광고 배너

한국경제 웹의 광고배너 3종을 뉴닉 스타일과 비교. 현재 배너는 광고처럼 보이는 전형적인 배너 모양인 반면, 뉴닉은 이미지와 텍스트 사이 여백을 넉넉히 둬서 광고처럼 느껴지지 않는 디자인(교보문고 느낌)을 사용함 — 참고할 만한 포인트.

## 문제정의 · 가설 · 페인포인트 · 니즈

**문제정의**
정보 탐색형 고객에게 한경 뉴스를 제공할 때, 지면 특유의 가독성과 학습 경험이 디지털에서 손실되고 있다. 이로 인해 이들이 콘텐츠를 학습 자료로 소비하고 싶어도 니즈를 충족시키지 못하는 상황. 한편 입문자는 지면·디지털 모두 매체 특성에 익숙하지 않고, 경제 공부를 위해 경제 뉴스를 소비하고 싶어도 시작하기 어려워함.

**가설**
지면의 레이아웃·서체가 주는 신뢰감과 몰입감을 유지하면서도, 모바일 환경에 최적화된 가독성과 실감형 학습 인터랙션(형광펜 하이라이트 등)을 제공하면, 정보 탐색형 고객들이 한경 콘텐츠를 학습 자료로 채택하고 이를 SNS 인증을 통해 자발적으로 루틴화할 것이다. 또한 게임 콘텐츠로 입문자는 쉽게 경제에 접할 수 있고 리텐션을 가져올 수 있을 것이다.

**페인포인트**
- 정보 탐색형 고객: 지면 뉴스가 디지털화되면서 가독성이 떨어짐(지면처럼 한눈에 보이지 않음). 형광펜·밑줄·메모 등 학습 행위를 한경 앱 안에서 동일하게 재현할 수단이 없음. 학습 루틴화를 지원하는 기능이 부재.
- 입문자: 전문적이고 신뢰감 높은 한경 이미지에 이끌려 입문하려는 사람은 있지만, 입문자에게는 장벽이 너무 큼.

**니즈**
- 모바일 웹에서도 지면 특유의 느낌(신뢰감, 정돈된 레이아웃)을 유지한 채 높은 가독성으로 기사를 읽고 싶음.
- 종이에 하던 것처럼 형광펜·밑줄 표시를 하며 능동적으로 학습하고 싶음.
- 학습 결과(하이라이트, 완독 기록 등)를 SNS에 공유하기 좋은 형태로 손쉽게 만들고, 이를 통해 학습 루틴을 지속하고 싶음.
- 경제 정보를 쉽게 접하고 싶음.

## 결론

전체적으로 요소가 너무 많아서 피로도가 높고, 그냥 보기 싫어지는 수준(웹보다는 덜하지만). 애초 방향은 "한경 지면으로 경제 공부를 하는 사람들이 있으니, 지면을 잘 디지털화해서 가독성을 높이고 공부 환경을 제공하자"였는데, 기존 한경 구조 자체가 너무 복잡해서 **기존 한경을 개선하기보다는 신규로 접근하는 게 맞는 방향**으로 보임. 가독성 높은 지면을 활용한 새로운 구조의 공부형 모바일 웹을 만들어야 할 듯. 분석하다 보면 자꾸 "한국경제 + 모바일한경 통합" 느낌으로 흘러가게 되므로, 방향을 명확히 잡을 필요가 있음.
