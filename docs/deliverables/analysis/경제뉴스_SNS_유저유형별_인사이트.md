# 경제뉴스 소비 SNS 유저 유형 인사이트

## 1. 유형별 정리

| 유형 | 특징 | 사례 |
|---|---|---|
| 전통 학습형 → 콘텐츠 생산형 | 종이신문 줄긋기 습관이 SNS 콘텐츠 생산으로 확장. 노하우 자체를 상품화 | 포스타입에서 노하우 전수 콘텐츠로 수익화 |
| 툴 활용형 | 직접 도구를 만들어 학습과 콘텐츠 생산을 겸함 | 바이브코딩 경제뉴스 요약 앱, 노션 기사-노트 템플릿 제작·공유 |
| 일반계정 자기계발형 | 투자 목적이 아닌 자기계발·공부 인증 차원의 루틴 전시 | 경제공부 스트릭, 달력·성취 인증샷 |
| 입문자 큐레이터형 | 기초적이고 입문자 눈높이의 콘텐츠 추천. 경제뉴스뿐 아니라 책·EBS 같은 바이블적 교양서 추천도 많음 | "이것부터 읽어" 류 추천 리스트 |
| 생활/일상/꿀팁 크로스오버형 | 투자 전문계정이 아닌 생활계·일상계·꿀팁 계정도 경제뉴스 읽는 법을 추천 | 꿀팁 계정의 밀리의서재 월간구독 한경 추천 |

## 2. 종합 인사이트: 3가지 축

| 축 | 구분 | 설명 |
|---|---|---|
| 축1. 계정 성격 | 투자 전문계정 vs 일상계/생활계 | 경제뉴스를 다루는 계정이 본업 성격(투자)인지, 곁가지 콘텐츠(일상·꿀팁)인지 |
| 축2. 소비 vs 생산 | 소비자 vs 생산자(루틴 과시형 / 콘텐츠 생산형) | 정보를 소비만 하는지, 직접 만들어내는지. 생산자는 다시 "루틴·성취 전시형"과 "요약앱·템플릿·노하우 판매 같은 실질적 결과물형"으로 나뉨 |
| 축3. 콘텐츠 심화도 | 입문 콘텐츠 vs 심화 콘텐츠 | 일상계는 바이블적 교양서·"이것부터 읽어" 식 입문 콘텐츠 위주, 투자 전문계는 심화 콘텐츠로 이어짐 |

## 3. 3축 교차 분석: 4분면 포지셔닝

축2(소비/생산)와 축3(입문/심화)을 교차하면 유저들의 포지션이 뚜렷하게 나뉜다.

| | 소비 중심 | 생산 중심 |
|---|---|---|
| **입문 콘텐츠** | 일상계 눈팅족 — 교양서·EBS 추천을 보고 따라 읽는 수동적 학습자 | 동기부여형 인플루언서 — 자기계발 인증(달력, 스트릭)으로 팔로워 유입, 초심자 대상 큐레이션 제공 |
| **심화 콘텐츠** | 투자 실전 소비자 — 경제뉴스를 실제 투자 판단 자료로 소비 | 노하우 판매형 전문가 — 요약앱·템플릿·유료 콘텐츠(포스타입 등)로 수익화하는 생산자 |

- **왼쪽 위(입문×소비)**가 가장 저변이 넓은 잠재 유입층: 자기계발 니즈는 있으나 아직 투자 전문 콘텐츠까지는 안 감. 진입장벽 낮은 콘텐츠·큐레이션으로 유입시키기 가장 좋은 지점.
- **오른쪽 위(입문×생산)**가 확산의 핵심 동력: 팔로워 관점에선 "전문가"가 아니라 "나와 비슷한 사람이 열심히 하는 모습"이라 신뢰·모방 유발. 성취 전시 장치(달력, 스트릭)가 이 유형의 참여를 늘리는 핵심 훅.
- **오른쪽 아래(심화×생산)**가 수익화 최종 단계: 정보를 공유하다 노하우 자체를 상품화. 무료 정보공유 → 팔로워 확보 → 유료 전환(포스타입 등)의 퍼널이 이 사분면에서 완성됨.
- **왼쪽 아래(심화×소비)**는 실제 투자자 그룹으로, 앱 사용성이나 정보 밀도에 더 민감할 가능성.

## 4. 시사점

콘텐츠 유입 퍼널은 "일상계 입문 콘텐츠 소비 → 자기계발 인증 생산 → 심화 학습 → 노하우 상품화"의 단계로 이동하는 경향이 있음. 따라서 입문자를 위한 큐레이션·성취 전시 기능을 강화하면 상위 단계(심화·생산·수익화)로의 전환을 자연스럽게 유도할 수 있음. 경제뉴스는 "전문 정보"가 아니라 "자기계발 인증 아이템"으로 먼저 소비되고, 그 위에서 전문성과 수익화가 쌓이는 구조.
