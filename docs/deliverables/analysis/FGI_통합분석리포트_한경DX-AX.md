# FGI 통합 분석 리포트
### 한국경제 DX/AX 저널리즘 서비스 PoC
**대상 기록:** 2026-07-13(1차) · 2026-07-14(2차) | **참여자:** 4인

---

## 0. 한 장 요약 (Executive Summary)

> **"광고 없는 신뢰도 높은 핵심 요약" 하나로 수렴했다. 게이미피케이션은 사실상 전면 부결됐다.**

1. **만장일치 1순위 = 광고 제거 + 핵심 요약 엔진.** 개발비 100만원 배분, 월 9,900원 지불의향, "지금 당장 만들어야 할 딱 하나" — 세 질문 모두에서 동일한 답이 나왔다. 이 정도의 수렴은 FGI에서 드물다.
2. **게이미피케이션은 4명 중 3명이 거부.** 심지어 "기사를 다 읽어야 게임을 이길 수 있다"는 강제 장치를 제시해도 손승호·강종희·조기원은 **게임을 포기하겠다**고 답했다. 3D 하우스에서 신문까지 걸어가는 동선은 "**무료라도 안 쓴다**"는 반응.
3. **'한경 페이퍼'(하이라이트 + AI 요약)는 유일하게 전원 호평.** 1차에서 이 기능을 제외하고 물었을 때 대안이 잘 나오지 않았다는 점 자체가 신호다.
4. **지불 의향: 3/4 YES (9,900원).** 단 조건은 "광고 제거 + 검증된 요약". 강종희(시니어)는 **NO** — 대신 "글자만 키워주면 무료로 매일 본다".
5. **'내 지갑 번역기'의 최대 리스크는 기능이 아니라 신뢰다.** 자산 정보 제공에 대해 젊은층은 조건부 허용, 중장년·금융권 종사자는 명확히 거부. "언론사가 내 금융 데이터를 다룰 만큼 보안을 신뢰할 수 있나"가 핵심 저항.

## 3. 니즈 (Needs) — Must / Should / Could

### 🔴 Must Have
- **N1. 광고 제로 + 핵심 요약 큐레이션** — 전원 1순위. 유일한 지불 트리거.
- **N2. 신뢰 근거의 명시** — 출처, 기준시점, 통계 근거를 본문 상단에 구조화. (조기원: "잘 정리된 데이터야말로 시간을 아껴주는 가장 확실한 도구")
- **N3. 쉬운 읽기 모드** — 용어 자동 풀이 + **큰 글씨**. 손승호(실무 인사이트 추출)와 강종희(시니어 접근성)가 동시에 지지한 **유일한 세대 교차 기능**.

### 🟠 Should Have
- **N4. 하이라이트 → AI 요약 → 내 노트 아카이빙 → 내보내기** ('한경 페이퍼'). 서담채(자소서), 조기원(업무 매뉴얼), 손승호(제안서) 모두 **각자의 산출물로 연결**된다는 게 핵심. 내보내기(노션/엑셀) 없으면 반쪽.
- **N5. AI 보이스 브리핑 (TTS)** — 이동 중 소비. 현재 8개 기능 중 귀로 쓸 수 있는 게 0개.
- **N6. 검증된 필진 페이지형 커뮤니티** — 익명 댓글판은 전원 거부. "검증된 전문가 + 운영진 큐레이션" 조건에서만 긍정.

### 🟡 Could Have
- **N7. 자산 영향도 분석기** (조기원 발안) — 기사 속 지표가 내 가계에 미치는 영향을 수치 시뮬레이션. *단, N8 해결 전제.*
- **N8. 최소 정보 기반 개인화** — 세금·등기 변동 알림 등. **자산 원문 데이터를 받지 않고** 카테고리 선택만으로 구현하는 우회 설계 필요.
- **N9. 자기계발 인증 카드** — 서담채 단독 강력 지지. 손승호는 "SNS 말고 포트폴리오 포맷이면 쓴다".

## 5. 결정적 발견 5가지

### ① 1차 → 2차에서 태도가 뒤집혔다
1차에서 "게임화, 조건 붙으면 괜찮을 듯"이라던 **립서비스가, 2차의 압박 질문(개발비 배분 / 9,900원 / 무료라도 안 쓸 것)에서 전부 무너졌다.** 손승호는 1차에서 "데이터 챌린지면 매일 들어갈 것 같다"고 했지만, 2차에선 "게임을 위해 기사를 읽으라면 **그냥 포기한다**"고 답했다.
→ **정성 데이터의 신뢰 구간은 압박 질문 쪽에 있다.**

### ② 게임의 보상 구조를 잘못 짚었다
이 그룹이 원하는 보상은 캐릭터 성장이 아니라 **"내 자산·내 실력이 실제로 나아졌다는 증거"**다.
> 강종희: "캐릭터 키우는 재미보다 **내 돈 불어나고 세금 줄어드는 게 눈에 보여야** 진짜 재미지."
> 조기원: "성장의 척도가 캐릭터가 아니라 **본인의 자산 관리 역량 강화**가 된다면 기꺼이 시간을 내겠다."

**→ 게이미피케이션을 버릴 게 아니라, 성장 지표를 '펫/캐릭터'에서 '나의 자산·지식 자산'으로 갈아끼워야 한다.** 이게 이번 FGI의 가장 큰 전환 포인트다.

### ③ 인위적 마찰(friction)은 전부 실패한다
3D 하우스의 걷기 동선, 강제 퀴즈, 잦은 알림 — 세 가지 모두 "**정보 습득 효율을 방해하는 숙제**"로 인식됐다. 포켓몬고 이탈 경험이 4인 전원의 레퍼런스로 소환됐다는 점이 결정적이다.
**"놀이처럼 만들면 더 볼 것"이라는 가설은 이 세그먼트에선 기각.**

### ④ 공유는 목적이 아니라 부산물이다
링크를 보내겠다는 답은 모두 "**핵심 요약 리포트가 있다면**"이라는 조건 하에 나왔다. SNS 인증 자체가 동기인 사람은 서담채 1명뿐.
**→ 바이럴 설계는 '인증 카드'가 아니라 '요약 리포트 공유 링크'에 걸어야 한다.**

### ⑤ 시니어는 별도 세그먼트다
강종희는 **유일한 무과금 사용자**이며, 그의 요구는 단 하나 — **큰 글씨 + 어려운 말 풀이**. 커뮤니티, 게임, 인증, 개인화, 구독 모두 거부. 그러나 "그것만 해주면 매일 즐겁게 보겠다"고 했다.
**→ 시니어는 수익 세그먼트가 아니라 트래픽·접근성 세그먼트. '쉬운 읽기 모드' 하나로 커버 가능한 저비용 고효율 타깃.**

## 7. 권고 (Recommendation)

**MVP (Phase 1) — 3개월 내**
1. **광고 없는 핵심 요약 엔진** + 근거·출처·기준시점 구조화 표기
2. **쉬운 읽기 모드** (용어 툴팁 + 폰트 스케일링)
3. **하이라이트 → AI 노트 → 내보내기** (한경 페이퍼 축소판)
4. **페이월/로그인 팝업 UX 전면 재설계** — 본문 노출 후 유도로 전환

**Phase 2**
5. AI 보이스 브리핑 · 숏폼 메이커
6. 필진 페이지형 커뮤니티 (초대제 + 큐레이션)
7. 자산 영향도 분석기 — **단, 자산 원문 입력 없이** "관심 카테고리 선택"만으로 시작하는 저마찰 온보딩

**보류 / 재설계**
- 3D 하우스 · 3D 펫 · 재판 게임 · 머니워크 → **현 설계로는 부결.** 살리려면 보상 지표를 캐릭터가 아닌 **'나의 지식·자산 성장 대시보드'**로 재정의할 것.

## 8. 리서치 한계

- **n=4**, 정성 조사 → 정량 검증 필요(특히 지불의향 9,900원, 게이미피케이션 거부율).
- 4인 전원이 "정리·기록 성향"이 강한 편향된 샘플일 수 있음. **저관여·수동적 독자(게이미피케이션의 원래 타깃)가 이 그룹에 없다.** 게임화 부결 결론을 일반화하기 전에 **20대 저관여층·비독자 대상 별도 FGI**를 권고한다.
- 실물 프로토타입 없이 구두 설명만으로 진행됨 → 3D/게임 기능은 상상 기반 반응이라 실제 체험 시 평가가 달라질 여지 있음.
