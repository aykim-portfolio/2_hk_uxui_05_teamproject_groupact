# **한국경제 웹 메인 페이지 구조 분석 및 정보구조도(IA)**

본 문서는 한국경제 메인 페이지의 실제 레이아웃 구조를 정밀 분석하고, 이를 바탕으로 한 정보구조도를 순차적으로 정리한 기획 문서입니다.

## ---

**1\. 메인 레이아웃 및 UX/UI 주요 특징 분석**

* **고정형 뷰포트 (width=1240px):** 모바일 최적화(반응형 대응) 없이 데스크톱 해상도에 고정된 중앙 정렬 레이아웃을 제공합니다.

* **헤더 영역의 명확성 및 슬로건:** 로고 바로 아래에 슬로건("성공을 부르는 습관")이 고정 노출되며, 우측 상단에는 비즈니스 핵심인 구독 모델 CTA 3개(신문 구독, 한경 프리미엄9 구독, 로그인)가 나란히 배치되어 유료 독자 전환을 유도합니다.

* **아이덴티티 컬러 블록(Color Blocking) 활용:** 메인 상중단 영역에 다크 그레이(프리미엄9) ▶ 레드(경제) ▶ 민트(마켓) ▶ 블루(집코노미) 형태의 와이드한 배경색 블록을 적용하여 킬러 버티컬 브랜드를 시각적으로 강력하게 강조합니다.

* **중하단 화이트 인덱스 전환:** 미디어 플레이어 허브(Hankyung LIVE)를 기점으로 화이트 배경으로 전환되며, 텍스트와 썸네일 중심의 3\~4단 열(Column) 그리드로 촘촘하게 종합 뉴스 인덱스를 나열하는 전통적 언론사 구조를 채택했습니다.
