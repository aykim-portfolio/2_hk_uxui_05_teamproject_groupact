- 핵심 명제: **"기사를 끝까지 읽은 독자가 가장 강한 변호인이다"** — 읽기 완주에 대한 즉각적 보상 설계

## 1. 진입 시나리오 설계 (이번 POC의 핵심)

```
[한경 기사 열람]
   │  스크롤하며 읽는 중…
   ├─ 핵심 팩트 문장이 화면에 들어오면 → 형광펜 자동 스윕 + "🔑 증거 확보!" 토스트
   │                                     (우상단 배지: 증거 1/3 → 2/3 → 3/3)
   ├─ [진입점 A] 기사 중간 인라인 훅 — 증인 인용문 카드
   │     "위험은 충분히 설명했습니다" — 허풍선 PB
   │     "방금 읽으신 내용과 맞습니까?" → [🔍 이 발언, 지금 검증하기]
   │
   └─ [진입점 B] 기사 끝 CTA
         "이미 이 사건의 증거 3건을 확보하셨습니다"
         → [⚖️ 확보한 증거로 재판 참여하기 (3분)]  ※ 3/3 수집 전에는 비활성
              │
        [📁 사건 파일 생성 중…] — 수집한 기사 문장 3개가 파일로 옮겨지는 트랜지션 (2초)
              │
        [법정] 읽은 문장 3개가 그대로 증거 시트에 — 별도 학습 없이 즉시 플레이
              │
        [판결] 승소 → "기사로 돌아가기" (완료 배지 + 관련 심층 기사 3건)
               패소 → "기사 다시 읽기" (형광펜 문장 재확인 유도) / "바로 재도전"
```

### 설계 포인트
1. **읽기 = 수집**: 증거 문장(`data-ev`)이 읽기 영역에 완전히 들어오면 자동 수집. 유저에게 아무 행동도 요구하지 않음 — 읽기 흐름을 끊지 않는 마이크로 보상
2. **이중 진입점**: 몰입형 독자(끝까지 읽고 CTA로) / 회의형 독자(인용문 보고 "저거 맞아?" 하는 순간 훅으로). 인라인 훅 진입 시 미수집 증거는 자동 보충
3. **왕복 루프**: 게임 종료가 기사 이탈이 아니라 **기사 복귀**로 설계 — 승소 시 관련 심층 기사 추천, 패소 시 형광펜 문장 재독 유도 (기사 재소비 발생)
4. **읽기 완주 보상의 명시화**: 기사 끝 CTA 문구가 "이미 확보하셨습니다" — 완독 자체를 성취로 리프레임

## 2. 기능별 구현

### 2-1. 기사 화면 (한경 스타일)
- 네이비 상단바, 심층기획 카테고리 뱃지, SVG 인포그래픽 히어로, 기자 바이라인
- 기사 소재: "[그날의 시장] ③ 레고랜드 사태 3년" — 실제 사건 기반 회고 기획 기사 형식

### 2-2. 스크롤 증거 수집
- 증거 문장 3개: 회생신청 발표(9.28) / A1등급 부도(10.5) / 돈맥경화 대서특필
- 스크롤 이벤트 + `getBoundingClientRect` 직접 계산 (초기 IntersectionObserver 구현은 렌더링 프레임 의존성 때문에 프리뷰 환경에서 미발화 → 스크롤 핸들러로 교체, 전 환경 결정적 동작)
- 수집 연출: 형광펜 배경 0%→100% 스윕(0.9s) + "🔑 증거 N" 핀 + 배지 bump + 토스트

### 2-3. 법정 (POC_4 그래픽 이식)
- 판사·증인 SVG 캐릭터, 대화 엔진, 추궁(땀)/증거 제시/이의 있음! 슬램/경악 표정 등 POC_4 자산 재사용
- **증거가 "기사 발췌 문장"** 그 자체 — 인용 부호와 형광펜 색으로 표시해 "방금 읽은 그 문장"임을 시각적으로 연결
- 발언 3개 × 신뢰도 ⚖️ 3개, 재판 분량 약 3분 (기사 읽기의 부록 크기로 의도적 축소)

### 2-4. 판결 → 기사 복귀
- 승소: "반박 성공" 도장 → 기사 복귀 시 CTA 영역이 "🏆 재판 완료" 상태로 전환 + 관련 기사 3건으로 시선 이동(자동 스크롤)
- 패소: "기일 속행" → [기사 다시 읽기](상단 복귀) / [바로 재도전] 분기

## 3. 검증 방법
`preview_eval` 브라우저 자동화로 전 구간 DOM 검증:
- 초기 0/3 → 스크롤 단계별 수집(0→2→3) → CTA 활성화 + 확보 증거 3건 표시
- CTA 진입 → 사건 파일 트랜지션(증거 3건 적재) → 법정 → 추궁 → 오답(신뢰도 차감) → 정답 3연속 → "반박 성공" → 기사 복귀(완료 상태 + 관련 기사 3건)
- 패소 분기(3오답 → "기일 속행" → 기사 다시 읽기/재도전) 및 인라인 훅 진입(미수집 증거 자동 보충) 확인, 콘솔 에러 없음
