# 한경 뉴스 게이미케이션 프로토타입 모음

한국경제(한경) 뉴스 소비를 게임화하여 트래픽 전환을 극대화하는 4개 프로토타입 정리 문서. 각 프로젝트는 독립 폴더 + 독립 포트로 분리되어 있으며 아래처럼 서로 연결된다.

```
news-shortform (57919)   ─ 기사 URL → 숏폼 콘텐츠 자동 생성
whistle-pixel-battle (3457) ─ 기사 → 픽셀 배틀 피드 (BULL vs BEAR 베팅)  ← 최종 랜딩 허브
yeouido-tycoon (3458)     ─ 타이쿤 게임 → 뉴스 원문 파밍 → 게임 보상
pixel-factory (3459)      ─ 크롬 확장 → 한경 기사 원문 내 돌발 퀴즈
```

## 1. 한경 Whistle — 픽셀 배틀 피드
**폴더**: `whistle-pixel-battle/` · **포트**: 3457

### 개요
뉴스 기사 URL을 입력하면 AI가 기사의 핵심 주장(Bullish 신호)과 이를 반박하는 대체 데이터(관세청 수출입 통계, 구글 트렌드, 주가 등)를 자동 매칭해, 화면이 반으로 쪼개진 16비트 픽셀 게임 UI로 렌더링한다. 유저는 30초 배틀 피드를 본 뒤 [기사 신뢰 🟢] vs [과장/구라 🔴]에 가상 크레딧을 베팅하고, 실제 공시·통계로 진위가 밝혀지면 정산되어 보상과 티어가 오른다.

### 핵심 구성
- **AI 역발상 요약 엔진**: 기사에서 핵심 주장 + 정량 수치 추출
- **대체 데이터 매칭**: 관세청/구글트렌드/주가 등에서 상충되는 반박 데이터 자동 크롤링
- **픽셀 게임 렌더링**: 냥이 기자(BULLISH 브리핑) vs 데이터 골렘(BEARISH 반박 차트)
- **베팅 & 정산**: 실시간 투표 게이지, DART 공시를 진실 원장으로 하는 정산 오라클

### 구현된 프로토타입
세로 스와이프 배틀 피드(카드 3개), 픽셀 냥이 기자 스프라이트(캔버스 렌더 애니메이션), 반박 데이터 바차트(스텝 애니메이션), 30초 타임라인(냥이 브리핑 → 데이터 슬램 → 심판 부엉이 휘슬 → 베팅 오픈), 베팅 모달(스테이크 선택 → 크레딧 차감 → 세력 게이지 반영).

### 최초 기획 프롬프트
> 너는 미디어 플랫폼의 패러다임을 바꾸는 서비스 기획자이자, 레트로 게이밍 감성을 이해하는 풀스택 개발자야. "한국경제(한경)" 도메인을 활용해 뉴스 소비를 완전히 게임화(Gamification)하는 신개념 앱의 상세 아키텍처와 코어 로직을 설계해줘.
>
> **서비스 핵심 컨셉**: "한경 Whistle" — 유저들이 긴 뉴스 기사 페이지를 안 본다는 점을 역이용, 언론사의 권위를 내려놓고 뉴스를 '집단지성이 검증하는 16비트 레트로 금융 게임'으로 전환.
>
> **핵심 메커니즘**: [URL 입력 ➔ 픽셀 게임 자동 생성 알고리즘]
> 1. AI 역발상 요약 엔진 — 기자의 핵심 주장과 주요 수치 추출
> 2. 대체 데이터 자동 매칭 — 한경 데이터룸/공공 데이터 API에서 반박용 데이터 매칭
> 3. 픽셀 게임/비주얼 피드 렌더링 — 냥이 기자(BULLISH) vs 반박 데이터(BEARISH) 16비트 UI
>
> 요구사항: (1) 시스템 아키텍처(URL 입력 → 대체 데이터 매칭 → 렌더링 파이프라인), (2) 핵심 데이터 스키마(가상 JSON), (3) UI/UX 와이어프레임 설계.

이후 "픽셀 배틀 피드 프로토타입 만들어줘, 뉴스 숏폼메이커랑 다른 폴더 만들어서 합쳐지지 않게" 요청으로 실제 동작하는 프로토타입 구현.

## 2. 여의도 타이쿤 (Yeouido Tycoon)
**폴더**: `yeouido-tycoon/` · **포트**: 3458

### 개요
유저가 여의도의 작은 투자사 사장이 되어 회사를 키우는 16비트 타이쿤 게임. 일반 타이쿤과 달리 시간만 써서는 성장하지 않고, 게임 내 '돌발 투자 퀘스트'가 발생하면 실제 한경 뉴스 원문을 읽고 팩트(수치·키워드)를 찾아와야만 투자에 성공한다. 이 흐름이 게임 리텐션과 뉴스 랜딩 페이지 트래픽 유입을 동시에 견인하는 구조.

### 핵심 구성
- **돌발 이벤트**: 게임 내 폴더폰 팝업으로 긴급 투자 퀘스트 발생
- **정보센터(도서관) 루프**: 한경 정보센터 건물 입장 → [기사 원문 보러가기] → 실제 랜딩 페이지 이동
- **정보 파밍**: 뉴스 페이지에서 핵심 단서(브랜드명, 관세청 수치 등)를 찾아 게임 복귀 후 입력
- **보상**: 정답 시 게임머니 대량 지급 + 티어 업그레이드([방구석 키보드] → [시장의 지배자])

### 구현된 프로토타입
사무실 씬(픽셀 사옥 + 출퇴근 직원 애니메이션, 방치 이자), 돌발 퀘스트 폰 팝업, 정보센터(사서 부엉이 NPC + 타자기 대사 + 힌트 카드), 모의 기사 랜딩 페이지(신문 UI + 부엉이 컴패니언의 "뜨겁다/차갑다" 근접 힌트 + 탐정 게이지 + 완독 보너스 + 단서 채집형 텍스트 탭), 정답 모달(채집 단서 프리필, 오답 시 흔들림+힌트, 3회 실패 페널티), 보상 연출(픽셀 동전 낙하 + 사옥 실제 증축 + 다음 퀘스트 자동 발행).

### 최초 기획 프롬프트
> 너는 중독성 있는 모바일 타이쿤 게임 아키텍처와 미디어 플랫폼의 트래픽 유입 전략을 모두 설계할 수 있는 '게이미케이션 전문 프로덕트 매니저(PM)'야.
>
> **서비스 컨셉**: "여의도 타이쿤" — 유저가 여의도의 작은 투자사/증권사 사장이 되어 회사를 빌딩하고 자산을 늘려가는 16비트 레트로 시뮬레이션 게임. 핵심 차별점은 현실의 경제 뉴스 데이터(한경 뉴스)를 기반으로 '진짜 팩트 정보'를 수집해야만 투자에 성공하고 회사를 키울 수 있다는 점.
>
> **핵심 유입 메커니즘**: [돌발 투자 퀘스트 ➔ 뉴스 랜딩 페이지 펌프질]
> 1. 돌발 이벤트 발생 — 게임 내 스마트폰 알림 팝업으로 긴급 투자 퀘스트
> 2. 도서관(정보센터) 건물과 '정답지' 매칭 — [한경 독점 기사 원문 보러가기] 버튼으로 실제 랜딩 이동
> 3. 뉴스 정독 및 단서 파밍 — 핵심 단서(브랜드명, 관세청 수치, 기자 이름 등)를 찾아 복귀 후 입력, 정답 시 대량 보상
>
> 요구사항: (1) 게임 코어 루프(URL 흐름의 유저 경험을 단계별로 시각화), (2) 퀘스트-뉴스 매칭 알고리즘(URL → 퀴즈 빈칸 변환 로직), (3) 랜딩 페이지 UX 가이드라인(픽셀 테마 미니 위젯·힌트 가이드 인터페이스).

이후 "ㅇㅇ!" 확인 후 실제 플레이 가능한 프로토타입 구현.

## 3. 한경 픽셀 팩토리 (Pixel Factory) — 크롬 확장
**폴더**: `pixel-factory/` (extension + demo) · **데모 포트**: 3459

### 개요 (v0.1 → v0.2로 컨셉 전환)
- **v0.1 (최초 기획)**: 네이버 카페/블라인드 등 커뮤니티에서 경제 관련 글을 읽을 때 화면 구석에 픽셀 캐릭터가 튀어나와 미니 팩트체크 퀘스트를 던지고 한경 랜딩 페이지로 트래픽을 리다이렉트하는 확장 프로그램.
- **v0.2 (재구성 반영)**: 커뮤니티가 아니라 **한경 기사 원문 페이지 안에서** 동작하도록 전환. 기사 본문을 로컬에서 분석해 숫자 빈칸/단어/OX 퀴즈를 자동 생성하고, 독서 스크롤 진행률에 맞춰 냥이 분석가가 돌발 퀴즈를 출제하는 "리딩 게임" 구조로 변경.

### 핵심 구성
- **Manifest V3 확장**: `content_scripts`는 한경 기사 URL 패턴에만 매칭, `background.js`는 퀴즈 정책 배포 및 계측만 담당
- **퀴즈 자동 생성 엔진** (로컬 분석, 서버로 원문 미전송):
  1. 숫자 빈칸 퀴즈 — 수치+단위 문장에서 수치를 가리고 3지선다 (오답: 부호 반전/절반/2배)
  2. 단어(브랜드) 퀴즈 — 제목의 고유명사를 힌트와 함께 4지선다 (경쟁 브랜드가 미끼)
  3. OX 퀴즈 — 증감 표현 문장의 방향을 검증
  - 퀴즈는 기사 내 등장 위치 순으로 정렬되어 "읽은 만큼만" 출제됨(스크롤 유도)
- **CSP/CORS 대응**: Isolated World + closed Shadow DOM + 외부 통신은 전부 background 대행 — "우회"가 아닌 정식 크롬 확장 메커니즘으로 해결
- **게임 루프**: 냥이 스폰 → 스크롤 트리거 퀴즈 출제 → 정답 시 점수+콤보 → 완독 시 정독 등급(S/A/B/C) 카드 → 휘슬 배틀룸 랜딩 CTA

### 구현된 프로토타입
`extension/`(실제 크롬에 로드 가능한 MV3 소스: manifest.json, background.js, content.js)과 `demo/`(한경 기사 페이지를 모사한 가짜 사이트 + `chrome.*` API 셤으로 확장 코드를 수정 없이 그대로 구동)로 구성. 데모에서 스크롤에 따른 퀴즈 3종 자동 출제, 정답 판정, 콤보 배점, 완독 등급 카드, 휘슬 랜딩 이동까지 전 구간 동작 확인.

### 최초 기획 프롬프트 (v0.1)
> 너는 브라우저 확장 프로그램(Chrome Extension) 인프라와 성장 해킹(Growth Hacking) 기술을 모두 꿰고 있는 '시니어 프론트엔드 아키텍트 겸 그로스 매니저'야.
>
> **서비스 컨셉**: "한경 픽셀 팩토리" — 유저를 한경 뉴스/휘슬 랜딩 페이지로 유입시키기 위한 브라우저 확장 프로그램 및 위젯 시스템. 유저가 자주 가는 커뮤니티(네이버 카페/뉴스, 블라인드 등)에서 경제 관련 글을 읽을 때, 화면 구석에서 픽셀 캐릭터(냥이 분석가)가 튀어나와 미니 팩트체크 퀘스트를 던지며 한경 메인 랜딩 페이지로 트래픽을 리다이렉트.
>
> **고도화 요구사항**: [웹 스크래핑 → 인페이지 미니 게임 → 랜딩 전환]
> 1. 텍스트 파싱 및 실시간 매칭 엔진 — 페이지 텍스트에서 금융/산업 키워드 추출, 활성 배팅 룸과 매칭 시 픽셀 캐릭터 스폰
> 2. 인페이지 미니 팝업 UX/UI — 캐릭터 클릭 시 페이지 이탈 없이 3초 내 [기사 신뢰 🟢] vs [과장/구라 🔴] 선택, 선택 완료 시 상세 랜딩 페이지로 탭 이동
> 3. 차단 방지 및 도메인 최적화 — CORS/CSP 우회 가이드라인, 광고로 인식되지 않는 레트로 픽셀 디자인 및 도파민 자극형 플레이버 텍스트
>
> 요구사항: (1) 확장 프로그램 데이터 아키텍처(통신 흐름도), (2) 가상 Manifest.json 및 Content Script 구조, (3) 전환율 극대화 UX 레이아웃.

### 재구성 프롬프트 (v0.2)
> 커뮤니티 사이트가 아니라 실제 한국경제 기사 원문내에서 기사를 읽다가 퀴즈가 나오는 로직으로 구성해줘. 기사내용을 분석해서 다지선다 퀴즈나, 단어퀴즈 등 간단한 퀴즈를 내는 프로그램으로 재구성.

## 4. 한경 뉴스 숏폼메이커 (참고: 기존 프로젝트)
**폴더**: `news-shortform/` · **포트**: 57919 (autoPort)

세션 초반부터 존재하던 별도 프로젝트로, 한경 기사 URL을 입력하면 숏폼 콘텐츠(대본 등)를 자동 생성하는 Node.js 서버. 본 세션에서는 신규 기획 3종(Whistle, Tycoon, Pixel Factory)과 포트가 겹치지 않도록 격리하는 작업만 수행했으며, 상세 설계는 이 세션에서 다루지 않았다.

## 프로젝트 간 연결 구조

```
[news-shortform]         [pixel-factory 확장]
  기사 URL → 숏폼 콘텐츠     기사 원문 안에서 퀴즈 출제
                                    │ 완독 시 랜딩 CTA
                                    ▼
                          [whistle-pixel-battle] ← 최종 허브
                          기사 → 픽셀 배틀 피드 (BULL/BEAR 베팅)
                                    ▲
                                    │ 정보센터에서 기사 원문 이동 후 단서 파밍 → 복귀
                          [yeouido-tycoon]
                          타이쿤 게임의 돌발 투자 퀘스트
```

세 신규 프로젝트(Whistle, Tycoon, Pixel Factory) 모두 최종적으로 **한경 뉴스 원문 또는 Whistle 배틀룸**으로 트래픽을 모으는 구조로 설계되었으며, `.claude/launch.json`에 각각 독립 설정(포트 3457/3458/3459, autoPort)으로 등록되어 있다.

# ⛏️ Text Miner — 와르르 뉴스 스크랩

크롬 익스텐션. 뉴스 기사에서 텍스트를 드래그한 뒤 **`Shift + Enter`를 6번 연타**하면
"손맛" 이펙트와 함께 텍스트가 스크랩되어 저장되는 인터랙션 툴.

---

## 1. 컨셉

- 뉴스 기사를 읽다가 인상 깊은 문장을 드래그
- 광부가 곡괭이질하듯 `Shift+Enter`를 리드미컬하게 연타(6회)
- 화면 하단에서 스크랩 인벤토리 오버레이가 올라오며 텍스트 블록이 와르르 떨어지는 이펙트
- 저장된 스크랩은 별도 대시보드 탭에서 카드 형태로 모아보기 가능

---

## 2. 기술적 시행착오 (진짜 있었던 일)

### 최초 시도: 맥북 가속도 센서(Sudden Motion Sensor) 기반 "팜레스트 타격 감지"
- 아이디어: 웹/키보드 이벤트가 아니라 **맥북 하판을 실제로 툭 치면** 그 충격을 감지해 스크랩을 트리거하려 함
- `sensor_server.py`: Python + `websockets`로 로컬 서버(포트 8765)를 띄우고, `ctypes`로 macOS `IOKit` 프레임워크를 로드해 가속도계 raw 값(X/Y/Z)을 폴링(100Hz)하는 프로토타입 작성
- **막힌 지점**: M1~M4 애플 실리콘은 인텔 맥북과 커널 구조·보안 모델이 달라 SMS 커널 주소에 대한 저수준 접근이 막혀 있음 → 센서값이 `0`으로 고정되거나 아예 접근 불가
  - 현재 `sensor_server.py`의 `get_macbook_acceleration()`은 이 한계 때문에 **항상 더미값 `(0,0,1.0)`을 반환**하는 상태로 남아있음 (미해결 이슈, 사실상 폐기 예정 코드)
- 부가 문제: 설령 감지가 되어도 실사용 시 하드웨어를 세게 두드려야 해서 (1) 맥북이 상할 위험 (2) 타격 소음으로 인한 UX 저하

### 1차 피벗: 스페이스바 연타
- 브라우저 표준 키보드 이벤트로 100% 감지 가능해서 채택
- **실패 원인**: 기사 읽는 중 스페이스바 = 페이지 스크롤 다운 → 가독성 파괴, 치명적 UX 결함

### 2차 피벗 (최종 채택): `Shift + Enter` 연타
- 스크롤/텍스트 입력 등 기존 브라우저 동작과 충돌하지 않는 조합키
- 0.4초 이내 연속 입력만 "연타"로 인정 → 리듬감 있는 타격 손맛 유지, 6회 도달 시 트리거

**결론: 센서 기반 접근은 폐기되었고, 현재 동작하는 구현은 순수 키보드 이벤트(`Shift+Enter` ×6) 방식이다.**
`sensor_server.py`는 코드베이스에 남아있지만 실제로 익스텐션과 연결되어 사용되지는 않는 것으로 보임 (연결 여부 확인 필요).

## 3. 현재 파일 구성

```
text-miner/
├── manifest.json      # MV3 매니페스트. content script + background + action 정의
├── background.js      # 툴바 아이콘 클릭 → dashboard.html 새 탭으로 열기
├── content.js         # 핵심 로직: 드래그 감지, Shift+Enter 연타 감지, 이펙트, 저장
├── styles.css         # 하단에서 올라오는 오버레이 + 텍스트 블록 낙하 애니메이션
├── dashboard.html      # 저장된 스크랩을 카드 그리드로 보여주는 대시보드 페이지
├── dashboard.js        # chrome.storage.local에서 scraps 불러와 렌더링
└── sensor_server.py    # (미사용/폐기 예정) 맥북 가속도 센서 연동 시도 프로토타입
```

### manifest.json
- `manifest_version: 3`
- 권한: `storage`, `activeTab`
- content script를 `<all_urls>`에 주입 (`content.js` + `styles.css`)
- `action` 클릭 시 `background.js`가 대시보드 탭을 오픈

### content.js — 핵심 인터랙션
1. `mouseup` 이벤트로 드래그 선택 텍스트를 `lastSelectedText`에 임시 저장
2. `keydown`에서 `shiftKey + Enter` 감지
   - 이전 타격과 400ms 이내면 `hitCount++`, 아니면 리셋
   - `hitCount >= 6` 이면 `triggerScrapEffect()` + `saveScrapedText()` 실행 후 상태 초기화
3. `triggerScrapEffect(text)`
   - 화면에 `#text-miner-overlay`가 없으면 동적 생성(제목 + 컨테이너)
   - 30자로 텍스트 자르고, 랜덤 X 위치(20~80%) / 랜덤 회전(-20~20deg)을 부여한 블록을 추가
   - 2초 후 오버레이 자동 숨김 (`hideTimeout`으로 중복 타이머 방지)
4. `saveScrapedText(text)`
   - `{ text, url, title, date }` 객체를 `chrome.storage.local`의 `scraps` 배열에 append

### styles.css
- `#text-miner-overlay`: 기본은 `bottom: -180px`로 화면 밖에 숨겨져 있다가 `.active` 클래스 시 `bottom: 0`으로 슬라이드업 (`cubic-bezier` 이징)
- `.miner-text-block`: `fallAndBounce` 키프레임으로 위에서 떨어지며 바운스하는 느낌 연출

### dashboard.html / dashboard.js
- 다크 테마(네온 민트 `#00ffcc` 포인트) 대시보드
- `chrome.storage.local`에서 `scraps` 배열을 읽어 최신순으로 카드 렌더링
- 각 카드: 스크랩 텍스트, 출처 제목, 원문 링크, 저장 일시
- 스크랩이 없으면 빈 상태 안내 문구 표시

### background.js
- 익스텐션 아이콘 클릭 시 `dashboard.html`을 새 탭으로 오픈하는 단 3줄짜리 서비스 워커

### sensor_server.py
- Python `websockets` 서버(로컬 8765 포트)
- `ctypes`로 `IOKit` 로드 시도, `SMSData` 구조체 정의
- `get_macbook_acceleration()`은 Apple Silicon 제약으로 인해 실제 센서값 대신 더미 리턴
- 진동 델타(`> 0.3`)와 쿨타임(0.15s)으로 "HIT" 신호를 웹소켓으로 브로드캐스트하는 구조만 존재 — **크롬 익스텐션 쪽에 이 WebSocket을 구독하는 코드가 현재 content.js에는 없음**
