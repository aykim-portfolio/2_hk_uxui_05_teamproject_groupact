1. ## 한경 뉴스랜딩\_기능별 구현 정리

   한 줄 소개 내용: 듀오링고처럼 뉴스를 재밌게 공부하면서 토스·뱅크샐러드류 핀테크 앱의 "신뢰감 있는 트렌디함"을 기준점으로 삼은 PoC이다.  
   

| 기능 ID | 기능 분류 | 핵심 구현 내용 (Core) |
| :---- | :---- | :---- |
| 1-1 | 벤토 그리드 레이아웃 | 균일한 카드 나열 대신 카드뉴스(와이드) → 대표기사(와이드·크게) → 용어 플립카드+스트릭 카드(정사각 2개) → OX 티저(와이드) → 관심분야 뱃지(얇고 긴 와이드) → 모의투자 이슈(와이드, 유일한 다크 섹션) 순 비대칭 배치 |
| 1-2 | 카드뉴스 캐러셀 | 대표기사 내용을 4장으로 요약한 가로 스와이프 캐러셀(scroll-snap, 라이브러리 없음). 다크 배경 \+ 큰 타이포 \+ 그린 키커. 스와이프 위치와 도트 인디케이터 동기화 |
| 1-3 | 대표기사 → 기사 상세 → 퀴즈 플로우 | 헤드라인 카드 탭 → 기사 전문 풀스크린 시트 → **맨 아래 "오늘의 브리핑 3문 풀어보기" 버튼** → 같은 기사 기반 3문항 퀴즈 시트로 연결. 랜딩 화면 자체엔 퀴즈 진입 버튼을 두지 않아 "기사를 읽어야 퀴즈를 풀 수 있다"는 리텐션 장치로 설계 |
| 1-4 | 경제 용어 플립카드 | 탭하면 3D Y축 회전. 임의의 용어가 아니라 오늘 헤드라인에 실제로 등장하는 개념("피벗") 을 다뤄 단절감 없이 연결 |
| 1-5 | OX 티저 (재선택 가능) | 헤드라인 쟁점을 O/X 질문으로 재구성. 선택 시 블러 힌트 \+ "기사에서 확인하기" 노출. 버튼을 disabled 처리하지 않아 다시 눌러 선택을 바꿀 수 있음 |
| 1-6 | 브리핑 스트릭 카드 | "N일째 확인 중" 큰 숫자 \+ 얇은 라인그래프. 캐릭터·배지 없이 숫자와 그래프로만 습관화 지표 표현 |
| 1-7 | 관심분야 뱃지 카드 | "오늘 헤드라인과 같은 분야, 이번 달 최다 열람" 문구로 개인 통계도 헤드라인과 연결. 나머지 분야는 얇은 바 그래프로 은근하게 표시 |
| 1-8 | 모의투자 이슈 카드 | 티저 카드 탭 → 관련 기사 전문 → 매수/관망 투표(pill 버튼) → 투표율 막대그래프 → 관련기사 3건. |
| 1-9 | 스크롤 리빌 | IntersectionObserver로 카드가 뷰포트에 들어올 때 미묘한 페이드업. 과장된 바운스·캐릭터 애니메이션 배제 |

2. ## 한경 3D House\_기능별 구현 정리

   한 줄 소개 내용: 텍스트 피드를 걷어내고 실생활 미디어 접점을 3D 오브젝트화하여, 저관여 독자의 정서적 장벽을 낮추고 체류 시간을 높이는 탐험형 콘텐츠 공간화 POC이다.   
   

| 기능 ID | 기능 분류 | 핵심 구현 내용 (Core) | 상세 스펙 및 UI / 예외 처리 |
| :---- | :---- | :---- | :---- |
| **2-1** | **이동 & 3인칭 카메라** | • WASD 캐릭터 이동 • 마우스 드래그로 카메라 궤도 회전 (Yaw/Pitch) | • **벽·가구 충돌 판정:** XZ 평면 충돌 공유, 카메라가 벽에 막히면 앞으로 당겨져 벽 뚫림 방지 • **애니메이션:** Shift 달리기 기능, 이동 시 팔다리 반대 위상 스윙 |
| **2-2** | **공간 구성 & 뷰** | • 5개 룸(거실, 주방, 침실, 서재, 욕실) 단층 구성 • **M 키:** 지붕이 사라지는 '돌하우스' 오버뷰 전환 | • **개구부 처리:** 문/창문을 프레임+십자 살+유리로 실제 타공하여 외부 시야 확보 • **HUD:** 현재 위치(룸)에 따라 상단에 룸 이름 라벨 자동 표시 |
| **2-3** | 사물 상호작용 (POC 핵심) | • **거실 신문:** 클릭 시 신문 지면 스타일 기사 모달 팝업 • **거실 TV:** 한국경제TV 유튜브 라이브 임베드 재생 • **서재 컴퓨터:** 한경 공식 유튜브 영상 임베드 재생 | • **레이캐스팅:** 마우스 포인터 위치 기준 3D 레이캐스팅 판정 • **거리 체크:** 카메라가 아닌 **캐릭터 기준 거리**로 상호작용 가능 여부 체크 (3인칭 버그 수정 반영) |
| **2-4** | **시간대 시스템** | • 낮 →  오후 →  밤 순환 시스템 (실제 시간 기준 각 상태당 5분 유지) | • **크로스페이드:** 전환 마지막 30초 동안 하늘색·태양광·실내조명·노출값 부드럽게 변경 • **밤 연출:** 별빛 구현, 실내조명 강조 • **HUD:** 우상단 배지로 현재 상태 표시 (☀️/🌇/🌙) |
| **2-5** | **캐릭터** | • 3등신 캐릭터 구현 | • **비주얼:** 미정 • **메커니즘:** 이동 방향으로 몸 회전, 속도(걷기/달리기)에 따른 팔다리 스윙 강도 차등 적용 |
| **2-6** | **UI & HUD** | • 카드 \+ 라운드 코너(Corner Radius) • 디자인 톤앤매너 통일 | • **좌상단:** 물음표(?) 버튼 클릭 시 조작법 팝업 모달 • **우상단:** 시간대 배지 • **상단 중앙:** 룸 이름 라벨 • **우하단:** 돌하우스 뷰 토글 버튼 |

3. ##  한경 다마고치\_기능별 구현 정리

   한 줄 소개 내용: 뉴스 열람을 펫 육성(타마고치) 루프로 전환하여, 감정적 애착과 성장 욕구를 통해 독자의 리텐션을 높이고 다독을 유도하는 3D 인터랙티브 PoC이다.

| 기능 ID | 핵심 구현 내용 (Core) | 상세 스펙 및 연출 (Details) | UI 및 예외/시스템 처리 |
| :---- | :---- | :---- | :---- |
| **3D 씬 (Three.js)** | • 파스텔톤 하늘 배경 • 공중에 떠다니는 잔디 섬 구현 | • 섬 내부 오브젝트 배치 (꼬마 나무, 버섯, 구름) • 뉴스가 배달되는 핵심 오브젝트인 **'우편함'** 배치 | • 360도 공간 조망 (인터랙션 연계) |
| **캐릭터 (블롭 정령)** | • 3등신 비주얼 블롭 캐릭터 제작 | • 외형 특징: 미정 • **진화 시스템:** 성장 단계에 따라 외형 오브젝트 추가 | • 진화 조건 달성 시 상태 업데이트 |
| **먹이기 연출** | • 뉴스를 먹여 캐릭터를 성장시키는 핵심 연출 | • **포물선 애니메이션:** 우편함에서 신문이 캐릭터에게 날아감 • **리액션:** 캐릭터가 신문을 먹을 때 냠냠 찌그러지는 **스쿼시(Squash) 애니메이션** 적용 • **파티클:** 하트 파티클 이펙트 생성 | • **오브젝트 연동:** 연출과 동시에 우편함 깃발이 '딸깍'하며 내려가거나 움직이는 물리 연출 |
| **뉴스 배달함 (UI)** | • 뉴스 콘텐츠 브라우징 및 먹이기 트리거 시스템 | • **바텀시트(Bottom Sheet) UI** 구조 • **카테고리 필터 (6종):** 증권, 경제, 부동산, 국제, 테크, 생활 | • 뉴스 기사 읽기 모달 팝업 • 모달 내 캐릭터에게 뉴스를 줄 수 있는 **\[먹이기\]** 버튼 배치 |
| **인터랙션** | • 사용자와 3D 환경 간의 실시간 상호작용 | • **씬 회전:** 화면 드래그로 Three.js 카메라 궤도 회전 • **쓰다듬기:** 캐릭터 탭(클릭) 시 하트 이펙트 발생 | • **정령 상태 표시:** 기분 상태에 따라 실시간으로 변화하는 **말풍선 대사** 출력 |
| **이벤트 처리** | • 게임 내 주요 분기점 및 상태 알림 시각화 | • **성장 알림:** 부화 및 진화 성공 시 축하 오버레이 팝업 • **상태 제한:** 캐릭터가 잠들었을 때 행동 제한 및 잠들기 경고 오버레이 | • **피드백:** 재화나 경험치 획득 시 화면에 띄워주는 **획득량 토스트(Toast) 알림** |
| **통계 HUD & 시스템** | • 플레이 데이터 시각화 및 데이터 보존 | • **대시보드:** 먹은 총 기사 수, 영양 밸런스(n/6), 최애 카테고리 실시간 반영 • **테스트 기능:** 개발 및 시연용 **데모 배속 토글 버튼** 구성 | • **데이터 저장:** 세션이 종료되어도 데이터가 유지되도록 localStorage 기반 자동 저장 기능 구현 |
