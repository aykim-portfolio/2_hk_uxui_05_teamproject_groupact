# 내 지갑 번역기 — PoC 기능정리

> 한국경제 랜딩페이지(hankyung.com) 위에 얹는 **개인화·유튜브 연동·게이미피케이션** 3종 기능 PoC
> 파일: `kay_지갑 번역기poc.html` (단일 HTML, 데스크톱 웹, 별도 설치·빌드 불필요)

---

## 1. 컨셉 & 문제의식

| 구분 | 내용 |
|---|---|
| 문제 | 경제뉴스는 "읽는다"보다 "공부한다"에 가까워 부담스럽고, 기사가 내 삶과 어떻게 연결되는지 보이지 않는다 |
| 해결 컨셉 | ① 뉴스를 **"내 돈에 미치는 영향"으로 번역** ② 즐겨보는 **한경 유튜브 방송과 기사를 연결** ③ 읽기 행동을 **XP·퀴즈·미션으로 보상**해 습관화 |
| 베이스 | 실제 한경 랜딩페이지 재현 (헤더·GNB·시세 티커·3단 뉴스 그리드·PREMIUM9 배너) 위에 기능 배너 2개를 추가하는 구조 |
| 특징 | 두 기능은 **완전히 독립** — 각자 배너→온보딩→상태 바를 갖고 개별 ON/OFF |

## 2. 화면 구성

```
헤더 (날짜·구독·로그인 / 로고 / GNB / 시세 티커)
├─ 💰 내 지갑 번역기 배너 (청록) ─── ON 시 → 스티키 프로필 바
├─ 📺 오늘 방송 기사 모아보기 배너 (빨강) ─ ON 시 → 방송 바
├─ 메인 3단 그리드: 좌측 헤드라인 │ 중앙 히어로 │ 우측 사이드바
│   └ 사이드바: 내 지갑 브리핑 + 방송 모아보기 모듈 + 기사 목록
├─ 한경 PREMIUM9 배너
└─ 우하단 고정: 🎮 경제 레벨 위젯 (XP·미션)
오버레이: 온보딩 모달 ×2, 미리보기 오버레이 ×2, 방송 모아보기 풀스크린 뷰
```

뉴스 콘텐츠: 실제 지면 구성을 본뜬 **기사 9건** (반도체 클러스터, 코스피, 증시 랠리, 입주물량, 삼성 노조 2건, AX 서밋 + 비경제 2건)

## 3. 기능 1 — 💰 내 지갑 번역기

### 진입 & 미리보기
- 티커 아래 청록 배너: "어려운 경제뉴스, 이제 '내 돈에 미치는 영향'으로 읽으세요" + `30초 만에 시작하기`
- **`어떻게 보이나요?` 미리보기 오버레이**: 같은 기사의 Before(지금의 기사) ➜ After(번역기 ON) 비교. 상황 칩을 눌러가며 **"같은 기사, 사람마다 다른 번역"**을 켜기 전에 체험 — 개인정보 입력 저항을 낮추는 가치 선(先)제시 온보딩

### 온보딩 — 내 상황 선택 (총 20개 태그, 4그룹, 복수 선택)

| 그룹 | 태그 |
|---|---|
| 🏠 주거 상황 (5) | 전세대출 / 주택담보대출 / 월세 거주 / 자가 보유(대출 없음) / 무주택·청약 준비 |
| 📈 투자 상황 (7) | 삼성전자 주주 / 국내주식 / 미국주식 / 코인·가상자산 / 달러·금(안전자산) / 연금·ISA / 예·적금 위주 |
| 💼 하는 일 (4) | 직장인 / 자영업자 / 프리랜서 / 취준생·학생 |
| 🎯 재테크 목표 (4) | 내 집 마련 / 종잣돈 모으기 / 노후 대비 / 부수입 만들기 |

- 선택 정보는 기기(localStorage)에만 저장된다는 프라이버시 문구 포함
- 모든 태그는 최소 1개 이상의 기사에 매핑되어 있어 어떤 조합을 골라도 빈 결과가 없음

### 뉴스별 "내 지갑 영향" 카드
- 적용 순간 **AI 분석 느낌의 스켈레톤 로딩** 연출 후 표시
- 구성: 방향(▲호재/▼부담/─중립) + 태그 + 한 줄 번역 + **영향도 배지 3단계** (`영향 커요` / `체크해 보세요` / `참고`)
- 기사당 매칭 태그 중 영향도 상위 **최대 2건** 표시, `AI 번역 · 참고용` 명시
- 예: 입주물량 기사 × 전세대출 → "▼ 재계약 때 보증금 인상 요구 가능성이 커졌으니 갱신청구권 사용 계획을 미리 세워두세요 · 영향 커요"
- 비경제 기사(야구부 사과 등)에는 "💰 내 지갑과 직접 관련은 낮은 뉴스예요" — 선별력 표현

### 오늘의 내 지갑 브리핑 (사이드바)
- "오늘 주요 뉴스 9건 중 **N건**이 내 지갑과 연결돼 있어요" + 영향도 상위 3건 요약 카드

### 상태 관리
- ON 시 상단 **스티키 프로필 바**: 선택 태그 칩 + `내 상황 수정` / `끄기`
- 새로고침해도 유지 (`wallet_profile`)

## 4. 기능 2 — 📺 오늘 방송 기사 모아보기 (독립 기능)

### 진입 & 미리보기
- 빨간 배너: "즐겨보는 한경 유튜브 프로그램을 고르면, 오늘 아침 방송에서 다룬 기사를 한자리에" + `프로그램 선택하기`
- **`어떻게 보이나요?` 미리보기 오버레이**: 프로그램 칩을 눌러가며 "기사에는 배지가 붙고 + 사이드바엔 모아보기가 생겨요" 2단 미리보기

### 프로그램 선택 (전용 모달)

| 프로그램 | 진행자 | 오늘 다룬 기사(목업 매핑) |
|---|---|---|
| 🌅 모닝루틴 | 임현우 기자 | 반도체 클러스터, 코스피, 증시 랠리 (3건) |
| 🗽 월스트리트나우 | 김현석 기자 | 코스피 (1건) |
| 🏘️ 집코노미TV | 집코노미팀 | 서울 입주물량 (1건) |
| 📊 주코노미TV | 증권부 | 증시 랠리, 삼성 DX노조 (2건) |

### 기사 방송 배지
- 선택한 프로그램이 오늘 다룬 기사에 "📺 모닝루틴 오늘 방송에서 다룸 →" 빨간 배지 부착
- **배지 클릭 → 전용 모아보기 뷰로 진입**

### 사이드바 모아보기 모듈
- 프로그램별 카드: 이름 · 진행자 · `모아보기 ↗` · `다시보기 ▶` + 오늘 다룬 기사 목록
- 기사 클릭 시 해당 기사 위치로 **부드러운 스크롤 + 빨간 하이라이트**

### 전용 모아보기 뷰 (풀스크린)
- 방송 헤더(프로그램명·진행자·날짜) + `← 뉴스홈으로`
- 방송 다시보기 목업 플레이어
- **읽기 진행률 바**: "오늘 방송에서 다룬 기사 3건 · 2건 읽음" (완주 시 🏁)
- 기사 카드: 번호 + 제목 + 요약 + (지갑 번역기 ON이면) **내 지갑 영향 라인 연동 표시** + `기사 본문 보기 → +10 XP`
- 읽은 기사는 초록 배경 + `읽음 ✓` 칩
- 하단 **🎯 오늘의 방송 퀴즈** (프로그램별 상이): 오답 시 재시도 유도, 정답 시 해설 + XP

### 상태 관리
- ON 시 빨간 방송 바: 프로그램 칩 + `프로그램 수정` / `끄기` (`wallet_programs`)
- 지갑 번역기와 상호 독립 — 한쪽만 켜기/끄기 가능

## 5. 기능 3 — 🎮 게이미피케이션

### 경제 레벨 위젯 (우하단 고정)
- 레벨 캐릭터 + 레벨명 + XP 진행바 + "다음 레벨까지 N XP" + 🔥 연속 출석(목업)
- **오늘의 미션 4종 체크리스트**: 번역기 켜기 / 지갑 영향 확인 / 방송 기사 1건 읽기 / 방송 퀴즈 맞히기

### XP 규칙

| 행동 | XP | 중복 방지 |
|---|---|---|
| 내 지갑 번역기 시작 | +20 | 1회 |
| 내 지갑 영향 카드 확인(클릭) | +10 | 1회 |
| 방송 모아보기 시작 | +15 | 1회 |
| 방송 기사 읽기 | +10 | 기사당 1회 |
| 한 방송 기사 완주 | +30 | 방송당 1회 |
| 방송 퀴즈 정답 | +30 | 방송당 1회 |

### 레벨 체계 (5단계)
🌱 경제 새싹(0) → 👀 경제 관심러(50) → 💡 **경제 똑똑이**(120) → 🎯 경제 고수(250) → 🏆 경제 프로(400)

- 획득 순간 토스트(+N XP · 사유), 레벨업 시 "레벨 업!" 추가 토스트
- 상태 저장: `hk_xp`(누적), `hk_earned`(획득 키 목록 — 중복 방지)

### 방송 퀴즈 (4종, 방송 내용 기반)
- 예: 모닝루틴 → "오늘 코스피가 지켜낸 지수선은?" (7,000/8,000/9,000)
- 오답: 해당 보기 빨간 표시 + "다시 골라보세요" / 정답: 초록 표시 + 💡 해설 + +30 XP

## 6. 기술 구조

- **단일 HTML 파일** (HTML+CSS+Vanilla JS), 외부 의존성 없음. 인라인 onclick 대신 `addEventListener` 바인딩(스크립트 제한 환경 대응)
- 상태 저장: `localStorage`

| 키 | 내용 |
|---|---|
| `wallet_profile` | 내 지갑 태그 배열 |
| `wallet_programs` | 선택한 유튜브 프로그램 배열 |
| `hk_xp` | 누적 XP |
| `hk_earned` | XP 획득 키 목록 (중복 획득 방지) |

- 데이터: 기사 9건 × 태그 20종 **영향 문구 매핑**, 방송 4종 × 기사 매핑, 퀴즈 4종 — 모두 하드코딩 시뮬레이션
- 파일을 더블클릭(file://)으로 열면 일부 환경에서 스크립트가 제한될 수 있어 **로컬 서버로 여는 것을 권장** (예: `python -m http.server`)

## 7. PoC 한계 & 실서비스 확장 과제

| 현재 (PoC) | 실서비스 시 |
|---|---|
| 뉴스×태그 영향 문구 사전 작성 | LLM이 기사 본문 기반 실시간 생성 — 영향도 판정 정확성 + **투자 조언 오인 방지 문구 가이드**("참고용" 표기)가 핵심 검증 과제 |
| 방송↔기사 매핑 하드코딩 | 방송 스크립트(STT)와 기사 유사도 매칭으로 자동화 |
| 온보딩 수동 선택 | 마이데이터 연동으로 자동 채움 확장 가능 |
| 퀴즈 사전 작성 | 방송 스크립트 기반 자동 생성 |
| 연속 출석 목업 | 실제 접속일 계산, 계정 연동 |

### 발표 프레임 제안
"경제뉴스는 어렵다"는 문제에 대한 3단 응답 — ① **번역**(내 지갑) ② **큐레이션**(방송 모아보기) ③ **습관화**(게이미피케이션). 유튜브 시청자가 웹에 착지했을 때 길을 잃는 문제(as-is 분석의 이탈 요인)에 대해 "임현우 기자가 오늘 말한 그 기사"를 바로 찾아주는 크로스미디어 응답이기도 함.
