# 프로젝트 PoC 기능 정리

이번 프로젝트에서 제작한 4개 PoC(퀴즈게임 / 여의도 타이쿤 / 한경서재 / Text Miner)의 기능을 정리한 문서입니다.

---

## 1. 퀴즈게임

기사 본문을 AI가 실시간으로 분석해 픽셀풍 캐릭터가 퀴즈를 던지고, 정답 시 즉시 포인트를 지급하는 인게이지먼트 기능입니다.

- **AI 실시간 본문 분석 엔진**: 독자가 기사 원문을 읽기 시작하면 AI가 배경에서 실시간으로 본문을 스캔해 핵심 맥락, 주요 경제 수치(매출·성장률 등), 인과관계(원인과 결과)를 파악하고 대기
- **인라인(In-line) 16비트 팝업 퀴즈**: 독자가 기사 하단·특정 단락을 다 읽고 스크롤을 내리면, 화면 우측 하단에 16비트 픽셀 '냥이 기자'가 등장해 "방금 읽은 내용, 복습 퀴즈 타임이다냥!" 하며 본문과 이어지는 퀴즈 창을 띄움
- **문맥 맞춤형 객관식 퀴즈 (3초 챌린지)**: AI가 기사 본문 기반으로 간단하고 직관적인 3지선다 퀴즈를 자동 생성
  - 예시 1 (수치 체크): "방금 읽은 뷰티 브랜드 PROTINI의 올 상반기 북미 수출 성장률은 몇 %였을까요? (① 150% ② 200% ③ 300%)"
  - 예시 2 (인사이트 체크): "기사에서 언급한 엔비디아의 주가 상승 핵심 원인은 무엇일까요? (① 가상화폐 호재 ② 차세대 AI 칩 출하 ③ 자사주 매입)"
- **즉시 채점 및 픽셀 피드백**: 기사 페이지 내에서 정답을 탭하면 페이지 이동 없이 그 자리에서 냥이 기자가 정답/오답 리액션을 보여주고, 픽셀 애니메이션과 함께 기사 속 정답 문장을 하이라이트(형광펜 효과)
- **근거 기반 정답 공유 창**: 정답 팝업의 버튼을 눌러 퀴즈 결과(예: "PROTINI 독해 퀴즈 성공!")를 픽셀 카드 이미지 형태로 커뮤니티·SNS에 공유
- **한경 포인트 즉시 적립 보상**: 퀴즈 정답 시 실제 결제에 쓸 수 있는 '한국경제 공식 포인트(Hankyung Point)'를 즉시 지급. 일일 정답 횟수에 따라 독자 프로필 티어(예: [방구석 키보드] → [시장의 지배자])가 상승해 시각적 성취감 제공

## 2. 여의도 타이쿤

뉴스 랜딩 페이지를 '정답지'로 활용해 유저 체류 시간을 늘리는 경영 시뮬레이션 게임입니다.

- **투자사 경영 시뮬레이션 UI**: 16비트 레트로 감성으로 나만의 증권사 빌딩을 업그레이드하고 자산을 불리는 코어 타이쿤 게임
- **실시간 뉴스 연동 돌발 퀘스트**: 현실의 경제 이슈를 바탕으로 "내일 테마주가 폭등할 것인가?" 같은 인게임 이벤트 팝업을 실시간 생성
- **한경 정보센터(도서관) 루프**: 힌트를 얻기 위해 인게임 건물을 클릭하면 [한경 독점 기사 원문] 랜딩 페이지로 인앱 브라우저 유입을 유도
- **인포메이션 파밍(단서 입력)**: 뉴스 랜딩 페이지에 숨겨진 팩트 수치·키워드를 유저가 직접 찾아 게임에 입력해야 퀘스트가 클리어되는 상호작용 매커니즘
- **랜딩 페이지 내 가이드 위젯**: 게임에서 넘어온 유저가 이탈하지 않도록 기사 본문 위에 픽셀 테마의 미니 가이드 위젯(예: "이 기사 어딘가에 브랜드명이 숨겨져 있습니다!")을 띄워 몰입도를 높임
- **문맥 근접 힌트**: 유저가 스크롤 중 정답이 있는 문맥 근처에 도달하면 캐릭터가 힌트를 주는 기능

## 3. 한경서재

Three.js 기반 3D 서재 공간에서 신문 기사를 종이접기로 '채굴'해 안경 아이템으로 수집하는 시뮬레이션 게임입니다.

### 기술 스택 & 기반

| 항목          | 내용                                                 |
| ------------- | ---------------------------------------------------- |
| 구조          | 단일 HTML 파일 (외부 애셋·빌드 없음)                 |
| 3D 엔진       | Three.js 0.160 (importmap CDN 로드)                  |
| 그래픽 스타일 | 파스텔톤 로우폴리(MeshToonMaterial) — 동물의 숲 무드 |
| 조명          | Hemisphere + Directional(그림자) + PointLight 웜필   |
| 텍스처        | Canvas API로 나무 바닥판·신문 지면 실시간 생성       |
| 폰트          | Jua, Gowun Dodum, Noto Serif KR (Google Fonts)       |

### 3D 공간 & 캐릭터

- 아늑한 서재: 나무 바닥, 벽/웨인스코팅, 창문, 책장, 러그, 화분, 스탠드 조명, 책상
- 동숲풍 주민 캐릭터: 귀·볼터치·꼬리·그림자 블롭, 걸을 때 통통 튀기 + 대기 시 숨쉬기 애니메이션
- 이동 3종: WASD/방향키, 바닥 클릭 이동(목적지 링 마커), 벽·가구 충돌 처리
- 궤도 카메라: 마우스 드래그 회전 + 휠 줌(6.5~26 거리), 캐릭터를 부드럽게 쿼터뷰로 추적

### 신문 → 종이접기 채굴 (핵심 인터랙션)

- 책상 위 신문 반짝이 마커 + 근접 힌트 말풍선 → 클릭 시 한국경제 실제 기사 팝업(마스트헤드·카테고리·바이라인·본문, 기사 5종)
- Shift ↔ Enter 번갈아 연타: 동시 입력이 아닌 교대 입력 방식, 같은 키 연속 시 무효(흔들림+오류음), 다음 키 하이라이트
- 실제 반접기 애니메이션: 매 타격마다 종이 절반이 접는 선을 축으로 3D로 뒤집힘(가로·세로 교대), 6회 → 1/64 크기
- 완성 시 종이 안경테로 변신 → 인벤토리로 날아가는 애니메이션

### 마네킹 전시 & 대시보드

- 벽 선반 4단 10개 얼굴 마네킹, 완성된 종이 안경테가 얼굴 위로 쌓임(무제한 수집)
- 호버 툴팁: 안경테에 마우스를 올리면 매칭된 기사 제목·카테고리·시간이 표시
- 안경 클릭 연출: 안경이 포물선으로 캐릭터에게 날아가 착용 → 얼굴 클로즈업 줌인 → 해당 기사 다시 읽기 팝업

### 경제 시스템 (퀘스트 + 상점)

- 스크랩 퀘스트: 일 3회 스크랩마다 +200P 적립(게이지 칩 + 포인트 뱃지 펄스 + 팡파레), 웰컴 300P
- 상점 오버레이(우측 하단): 옷 6종(구매 시 캐릭터 옷 색 실제 변경, 구매/입기/착용중 상태), 가구 6종(스툴·화분·러그·곰인형·스탠드·시계 → 서재 빈 자리에 팝인 배치)
- 잔액 부족 차단, 보유 아이템 처리

### 사운드 & 폴리시

- WebAudio 합성: 오르골풍 BGM 무한 루프(C–Am–F–G) + 발소리·종이접기·구매·팡파레 효과음, 음소거 토글
- 화면 셰이크, 카메라 흔들림, 반짝이 파티클, 토스트 알림 등 다수의 마이크로 인터랙션

## 4. Text Miner

기사 페이지에서 텍스트를 드래그 후 Shift+Enter를 연타해 기사를 스크랩하는 크롬 익스텐션입니다.

### 1) 텍스트 선택 감지

- `mouseup` 이벤트로 사용자가 드래그한 텍스트를 실시간 캡처
- `window.getSelection()`으로 선택 영역 텍스트를 추출해 임시 저장(`lastSelectedText`)

### 2) Shift+Enter 연타 스크랩 트리거

- `keydown` 이벤트로 Shift + Enter 조합 감지
- 400ms 이내 연속 입력만 "연타"로 카운트(리듬이 깨지면 카운트 리셋)
- 6회 연타 도달 시 스크랩 실행

### 3) 스크랩 이펙트 애니메이션

- 화면 하단에 스크랩 인벤토리 오버레이가 슬라이드업으로 등장(cubic-bezier 이징)
- 스크랩된 텍스트(30자 초과 시 말줄임)가 랜덤 위치·랜덤 회전각으로 떨어지는 바운스 애니메이션(`fallAndBounce` 키프레임)
- 2초 후 오버레이가 자동으로 슬라이드다운되며 사라짐

### 4) 데이터 저장

- 스크랩 시 `{ text, url, title, date }` 형태로 `chrome.storage.local`의 `scraps` 배열에 append
- 브라우저를 꺼도 유지되는 로컬 영속 저장소

### 5) 대시보드 (별도 탭)

- 익스텐션 툴바 아이콘 클릭 → `chrome.action.onClicked` → 새 탭에서 `dashboard.html` 오픈
- `chrome.storage.local`에서 `scraps` 전체를 불러와 최신순 정렬
- 카드 그리드 레이아웃으로 각 스크랩 표시: 인용문 텍스트, 출처(문서 제목), 원문 링크, 저장 일시
- 스크랩이 하나도 없을 때는 안내 문구("드래그하고 Shift+Enter를 연타해 보세요!") 노출
- 다크 테마 + 네온 민트(`#00ffcc`) 포인트, 카드 호버 시 위로 살짝 떠오르는(`translateY`) 인터랙션

### 6) 익스텐션 인프라 (MV3)

- `manifest_version: 3` 구조
- `content_scripts`: 모든 URL(`<all_urls>`)에 `content.js` + `styles.css` 자동 주입
- `background.js`: 서비스 워커로 아이콘 클릭 이벤트만 처리
- 권한: `storage`(로컬 저장), `activeTab`
