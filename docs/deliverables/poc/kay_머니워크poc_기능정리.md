# 머니워크 MoneyWalk — PoC 기능정리

> **"강아지랑 산책하며 줍는 경제뉴스"** — 강아지가 뉴스 냄새를 맡아주는 위치기반 AR 뉴스 수집 게임 (모바일 웹 프로토타입)
> 파일: `kay_머니워크poc.html` (단일 HTML, 별도 설치·빌드 불필요)

---

## 1. 컨셉 & 문제의식

| 구분 | 내용 |
|---|---|
| 문제 | 경제뉴스는 "공부해야 한다"는 부담 때문에 진입 장벽이 높다 |
| 해결 컨셉 | 뉴스를 **강아지 산책길로** 꺼낸다. 강아지가 뉴스 냄새를 맡고 멈춰 서면(부동산 앞 → 월세 시세, 증권가 → 코스피) 관련 뉴스가 튀어나오고, 이를 "줍줍"하는 수집 게임으로 소비한다 |
| 포지셔닝 | 기존 랜딩페이지 개선(접점 개선)과 달리, **경제뉴스의 신규 접점**을 만드는 별도 서비스 프로토타입 |
| 형태 | 모바일 웹 (390×844 폰 프레임, 데스크톱 브라우저에서도 폰 화면처럼 표시) |

## 2. 화면 구조

```
온보딩(최초 1회)
└─ 메인 앱
   ├─ 🐕 산책 (AR 뷰) ← 기본 탭
   ├─ 🗺️ 지도
   ├─ 📔 산책 수첩
   ├─ 바텀시트 (뉴스 스팟 상세) — 모든 탭 위에서 열림
   └─ 기사 리더 (끝까지 읽어야 줍줍)
상단 고정: 현재 위치 칩 + 레벨/XP 칩
하단 고정: 3-탭 바
```

**디자인 시스템**: 크림 종이(#faf6ec) 배경 + 잉크 라인(#23272f) 두들 + 크레용 톤 포인트(머스터드·벽돌·올리브·슬레이트·플럼) + 손글씨 폰트(Gaegu). 모든 UI 요소(칩·마커·카드·표지판)가 2px대 잉크 테두리와 오프셋 섀도로 손그림 스케치북 느낌을 유지

## 3. 기능 상세

### 3-1. 온보딩 (최초 진입)
- 위트 카피 헤드라인(손글씨 폰트): **"가로막힌 경제, 강아지랑 산책하면 돼"**
- `MONEYWALK · WALK THE DOG` — **내 지갑 상황 선택** (복수 선택, 2열 카드 그리드)
  - 전세·월세 살아요 / 주식 투자 중 / 장사해요(자영업) / 예·적금 위주 — 카드마다 목줄 색이 다른 두들 강아지
- 선택한 태그는 이후 모든 뉴스에 붙는 **"내 지갑 번역"의 기준**이 됨
- `건너뛰기` 가능 (이 경우 지갑 번역 라인 미표시)
- **두들 강아지 4마리 퍼레이드** 인트로(SVG 손그림, 둥둥 애니메이션) + 여백에 흩어진 손글씨 낙서("every thing is fine", "경제, 별거 아냐 멍", "walk the dog 🐾")

### 3-2. AR 산책 뷰 (메인)
- **카메라 화면 시뮬레이션**: 종이 질감 하늘 + 잉크 테두리 건물 + 스케치 도로 (동네마다 색감 다름)
- **산책 강아지 마스코트**: 목줄을 찬 옆모습 두들 강아지(SVG)가 도로 위를 걸으며 말풍선으로 안내
  - 기본: "킁킁… 뉴스 냄새! 🐾" / 동네 스팟 전부 클리어 시: "이 동네 산책 끝! 멍 🦴"
- **뉴스 스팟 마커**: 머스터드 점선 맥동 링 + 잉크 테두리 구슬 + 스팟 이름 + 거리 표시(예: 12m)
- 마커 탭 → 해당 스팟의 바텀시트 오픈
- 스팟의 뉴스를 전부 주우면 마커가 **회색(클리어) 상태**로 변경 + ✓ 표시
- 좌하단 레이더 칩: "🐾 뉴스 냄새 N곳"

### 3-3. 스팟 상세 바텀시트
- 슬라이드업 바텀시트 (배경 딤 탭으로 닫기)
- **① 실시간 시세 카드**: 스팟 성격에 맞는 생활 밀착 지표 + 등락 + 출처 표기
  - 예: 공인중개사 → "이 동네 원룸 월세 평균 78만원 ▲ 전년比 +9%"
- **② 발견한 뉴스 리스트** (스팟당 1~2건): 제목 + 한 줄 요약
- **③ 내 지갑 번역** (온보딩 태그와 매칭될 때만): "💰 🏠 전세·월세인 나에게: 재계약 때 월세 인상 요구 가능성이 커요…"
- **④ 기사 읽기 버튼**: `기사 읽고 줍기 📖 +15 XP` → **기사 리더로 이동** (줍기는 리더 안에서만 가능)
- 읽은 기사에는 제목 옆 `읽음 ✓` 칩, 주운 기사는 `주웠음 ✓` 비활성 버튼 표시

### 3-3b. 기사 리더 — 읽어야 줍는다
- 우측에서 슬라이드인되는 풀스크린 기사 화면: 발견 스팟 표기 + 기사 제목 + 본문(문단 3개, 뉴스 12건 전체 목업 작성) + 내 지갑 번역 카드
- **줍기 버튼은 본문 맨 끝에 있으며, 끝까지 스크롤해야 활성화**
  - 잠금 상태: `⬇ 기사를 끝까지 읽으면 주울 수 있어요` (비활성)
  - 스크롤이 바닥에 닿으면 → `이 뉴스 줍기 🫳 +15 XP` 활성화 + 읽음 처리
  - 본문이 화면에 다 들어오는 경우(스크롤 불필요)는 즉시 활성화
- 줍기 완료 시 `주웠음 ✓` 전환 후 스팟 시트로 자동 복귀(상태 갱신)
- 이미 주운 기사도 다시 읽기 가능 (버튼은 `주웠음 ✓` 고정)

### 3-4. 지도 뷰
- 격자+강 스타일의 약식 지도, 파란 점 = 현재 위치
- **동네 핀 3개** (핀별 뉴스 스팟 수 표시) — 탭하면 해당 동네로 이동(PoC라 순간이동) 후 AR 탭 자동 전환
- **도로표지판 위젯** (이정표 유머 컨셉): 다음 레벨까지 남은 XP를 고속도로 표지판으로 표시
  - `② ↑ 경제 관심러 40 XP / Gwansimneo` + 하단 `← 안 읽음 Anilgeum · 미룸 Mirum →`

### 3-5. 도감 뷰 — 컬러 폴더 컨셉
- **스팟별 폴더** 7개 (2열 그리드): 폴더 하나 = 뉴스 스팟 하나, 스팟마다 고유 컬러 (중개사 오렌지 / 은행 그린 / 편의점 브라운 / 증권 네이비 / 환전소 스카이블루 / 카페 퍼플 / 공실상가 레드오렌지)
- 폴더 구조: 상단 탭 + 뒷면 + 앞주머니 3겹, 주머니 사이로 **종이가 삐져나오는** 형태
  - 주운 뉴스: 흰 종이 (줄무늬 텍스트)
  - 미수집: 회색 **"?" 종이**
- 폴더 라벨: 좌하단 스팟 이름·위치, 우하단 큰 카운트 (`1/2`)
- 상태 표현: 하나도 못 주운 폴더는 회색 톤으로 잠김, 전부 모으면 초록 **✓ 배지**
- 폴더 탭 → 해당 스팟 바텀시트 바로 오픈
- 상단 **레벨 카드**: blob 캐릭터(레벨별 색·표정) + 레벨명 + XP 진행바 + 🔥 연속 산책 스트릭(목업)

### 3-6. 게이미피케이션 규칙

| 행동 | 보상 |
|---|---|
| 뉴스 줍기 — **기사를 끝까지 읽어야 가능** | +15 XP (뉴스당 1회) |
| 한 스팟의 뉴스 전부 줍기 | +30 XP "스팟 클리어! 🏁" |
| 레벨업 | 토스트 알림 "레벨 업!" |

**레벨 체계 (5단계)**

| Lv | 이름 | 필요 XP | 캐릭터 |
|---|---|---|---|
| 1 | 🌱 경제 새싹 | 0 | 초록 blob (무표정) |
| 2 | 👀 경제 관심러 | 40 | 노랑 blob |
| 3 | 💡 경제 똑똑이 | 100 | 주황 blob |
| 4 | 🎯 경제 고수 | 200 | 파랑 blob (놀람) |
| 5 | 🏆 경제 프로 | 350 | 보라 blob |

- 모든 XP 획득 시 상단 토스트(+N XP · 사유) 노출, 상단 레벨 칩·도감·도로표지판 실시간 갱신

## 5. 기술 구조

- **단일 HTML 파일** (HTML+CSS+Vanilla JS), 외부 라이브러리·서버 의존성 없음
- 상태 저장: `localStorage`

| 키 | 내용 |
|---|---|
| `mw_profile` | 온보딩에서 선택한 지갑 태그 배열 (null = 온보딩 전) |
| `mw_xp` | 누적 XP |
| `mw_collected` | 주운 뉴스 키 목록 (`스팟id_뉴스index`) |
| `mw_read` | 끝까지 읽은 뉴스 키 목록 (읽어야 줍기 가능) |
| `mw_loc` | 현재 동네 |

- **onTap 헬퍼**: click 이벤트가 씹히는 환경(터치·임베드 패널) 대비 `pointerup` 폴백 + 600ms 중복 방지 가드 — 모든 인터랙션에 적용
- 실제 GPS·카메라는 사용하지 않음 (화면 우하단에 "PoC · 실제 위치/카메라 미사용" 명시)

## 7. PoC 한계 & 실서비스 확장 과제

| 현재 (PoC) | 실서비스 시 |
|---|---|
| 거리 풍경 CSS 시뮬레이션 | 실제 카메라 + WebXR/AR Kit 기반 오버레이 |
| 동네 이동 = 지도 핀 탭 (순간이동) | GPS 기반 실제 위치 감지, 지오펜싱 스팟 발동 |
| 시세·뉴스 12건 하드코딩 | 한경 시세 데이터 API + 위치·업종 기반 뉴스 자동 매칭 |
| 지갑 번역 문구 사전 작성 | LLM이 기사 본문 기반 생성 (투자 조언 오인 방지 가이드 필요) |
| 스트릭 "3일째 산책" 목업 | 실제 접속일 기반 계산 |
| XP/수집 = 브라우저 로컬 저장 | 계정 연동, 부정 획득 방지 |
