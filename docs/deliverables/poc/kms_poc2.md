# POC_2 — 형광펜 하이라이트 → 액션아이템 내보내기 (모바일)

- 파일: `Proof_of_Concept/POC_2_mobile_highlight_actionitem.html` (독립 실행형 HTML, 더블클릭으로 바로 확인)
- 기반: `react-app` 실사용 컴포넌트/데이터 이식 — `ArticleHeader.jsx`, `Article.jsx`, `Sidebar.jsx`, `SubscriptionModal.jsx`, `levels.js`, `products.js`
- 목적: 저널리즘 DX/AX 논의에서 나온 UI 개선 기회요소 중 "독자 참여(하이라이트→공유)"와 "AI 탐색" 축을 모바일 화면에서 실제 코드로 검증

## 1. 기능별 구현 정리

### 1-1. 저널리즘 리스트 → 기사 원문
기사 카드 목록에서 원문으로 진입하는 기본 탐색 구조. 실제 `Header.jsx`의 로고·티커·내비게이션을 모바일 폭에 맞춰 재구성.

### 1-2. 형광펜 하이라이트 (쓰기 / 지우개)
- `ArticleHeader.jsx`의 5색 팔레트(`#ABF800 #8344FF #FF3CA4 #FF7D00 #143C7E`)와 아이콘을 그대로 사용
- `Article.jsx`의 `Range.surroundContents` 기반 하이라이트/지우개 로직을 실제 텍스트 선택으로 재현 (드래그 선택 → `<mark>` 삽입, 지우개 모드에서 선택 영역/클릭한 마크 제거)

### 1-3. 액션시트 (하이라이트를 탭했을 때)
형광펜·지우개를 모두 끈 상태에서 이미 칠해진 하이라이트를 탭하면 하단에 액션시트 등장 — **카드로 내보내기 / 스크랩하기 / 복사하기(실제 클립보드 복사) / 하이라이트 삭제**. 이 지점이 "형광펜 → 액션아이템"을 잇는 핵심 연결부.

### 1-4. 액션아이템 내보내기 (카드 편집)
- 하이라이트 문장이 카드 프리뷰에 자동 반영
- 배경: 색상 스와치 5종 + **실제 사진 업로드**(`input type=file` + `FileReader`, 반투명 스크림 자동 적용으로 텍스트 가독성 확보, 제거 버튼으로 원복)
- 비율 선택(1:1 / 4:5 / 9:16)
- "스크랩에 저장" / "공유하기" 두 갈래 CTA

### 1-5. 공유 → 보낸것 확인
공유 대상 시트(카카오톡 / 인스타그램 스토리 / 링크 복사 — 링크 복사는 실제 클립보드에 기록) → 공유 완료 화면(보낸 카드 썸네일 + 대상 확인) → "스크랩함에서 보기" 또는 "기사로 돌아가기"로 분기.

### 1-6. 스크랩함 — 경제지 특성 반영
소설/문학 하이라이트 스크랩(예쁜 문구 저장)과 차별화 지점. 스크랩 각 항목에 **스크랩 당시 시장 스냅샷**(코스피·원달러 환율·기준금리·3년 국고채), **용어 설명 칩**(탭하면 짧은 정의 펼침), **관련 기사 더보기**, **이슈 후속 소식 알림받기** 토글을 붙임 — "그 순간의 시장 맥락을 다시 볼 수 있게" 하는 것이 핵심.

### 1-7. 페이월 → 결제 (무료 1회 제한)
- 무료 회원은 카드 내보내기 1회까지만 허용, 이후 시도 시 페이월 시트 등장
- `SubscriptionModal.jsx` 톤을 재사용한 결제 화면("모바일 한경" 7,500원, 결제수단 선택, 결제 완료) → 결제 후 **하던 작업을 그대로 이어서 진행**(막혔던 카드 내보내기로 자동 복귀)

### 1-8. AI 궁금증 해결소 (Epic AI 모바일화)
- 데스크톱 고정 사이드바(`Sidebar.jsx`)를 **우하단 플로팅 버튼 + 도킹형 바텀시트**로 전환
- 시트 높이를 화면의 약 36%로 제한하고 배경 딤 처리를 없애 **기사 원문을 계속 보면서** 탭 전환·질문이 가능하도록 함(시트 바깥은 `pointer-events:none`으로 기사 스크롤/탭 그대로 유지)
- AI 대화(추천 질문 칩 → 질문 → 로딩 → 답변) / 다른 생각(이해관계자 카드 3장) 탭, 실제 카피 그대로 이식
- 페이월도 동일 룩으로 재현하며 **구독 상태(`subscribed`)를 액션아이템 내보내기 결제와 공유** — 한쪽에서 결제하면 두 기능이 동시에 잠금 해제됨(실제 앱의 `isPremium` 공유 구조 재현)

## 3. 검증 방법
모든 항목은 브라우저 자동화(`preview_eval`/`preview_snapshot`)로 실제 DOM 상태 변화를 확인: 하이라이트 생성 → 액션시트 → 무료 한도 초과 시 페이월 → 결제 → 카드 이어가기 → 공유 → 확인 → 스크랩 상세, AI 시트 잠금/해제/질문-답변까지 전 구간 정상 동작 확인.
