# 한경 페이퍼 (Hankyung Paper) — POC 정리

> 지면(종이신문) 특유의 감성과 학습 경험을 모바일에서 그대로 재현하는 경제 학습 앱 프로토타입.
> 단일 파일(`index.html`) 바닐라 HTML/CSS/JS로 구현.

---

## 1. 기획 배경

### 문제 정의
충성도 높은 고객(열독자)에게 한경 뉴스를 디지털로 제공할 때, 지면 특유의 가독성과 학습 경험이 손실된다.
콘텐츠를 학습 자료로 소비하고 싶어도 그 니즈를 충족시키지 못한다.
한편 입문자는 지면·디지털 모두 익숙하지 않아 경제 공부를 시작하기 어려워한다.

### 가설
지면의 레이아웃·서체가 주는 신뢰감과 몰입감을 유지하면서 모바일에 최적화된 가독성과
실감형 학습 인터랙션(형광펜 하이라이트 등)을 제공하면,

- **열독자**는 한경 콘텐츠를 학습 자료로 채택하고, SNS 인증을 통해 자발적으로 루틴화한다.
- **입문자**는 게임 콘텐츠로 쉽게 경제에 접근하고 리텐션을 형성한다.

### 페인 포인트
- **열독자** — 지면 대비 떨어지는 디지털 가독성, 형광펜·메모 등 학습 행위를 재현할 수단 부재, 학습 루틴화 기능 부재.
- **입문자** — 전문적·신뢰감 높은 한경 이미지로 진입하지만 장벽이 너무 큼.

### 핵심 니즈
- 모바일에서도 지면 특유의 느낌(신뢰감·정돈된 레이아웃)을 유지한 높은 가독성
- 종이에 하듯 형광펜/밑줄로 능동적 학습
- 학습 결과(하이라이트·완독 기록)를 SNS에 공유해 루틴 지속
- 경제 정보에 쉽게 접근

## 2. 앱 구조

하단 내비게이션 3탭 구성 — **게임 · 홈 · 마이**

```
┌─────────────────────────┐
│   지면 / 기사 리더 / 모달  │
│                         │
├─────────────────────────┤
│   🎮 게임   📰 홈   📓 마이  │
└─────────────────────────┘
```

샘플 기사 **8건** 내장 (카테고리 분포: 종합·금융 3 / 산업 2 / 국제·외환 1 / 부동산 1 / 입문·교육 1)

## 3. 기능 상세

### 3-1. 홈 — 신문 1면
- 제호·발행일·판 번호가 있는 **마스트헤드**, 3단 괘선 조판 등 실제 종이신문 레이아웃 재현
- 톱기사는 2단 조판 리드문, 나머지는 세로 괘선으로 나뉜 그리드
- 명조 서체 + 크림색 종이 질감 + 양끝 맞춤으로 지면 신뢰감 구현
- **완독한 기사 표시**
  - 오른쪽 하단 모서리가 종이처럼 접힘(dog-ear)
  - 기자명 옆 "완독" 배지
  - 카드 전체를 살짝 흐리게(opacity 0.5) 처리해 "이미 읽은 티"

### 3-2. 기사 리더 (필기 학습)
기사를 탭하면 지면 포맷 그대로 새 화면이 열림.

- **형광펜 (3색: 노랑·분홍·초록)** — 손끝 아래 텍스트를 인식해 **항상 글줄에 반듯하게 스냅**되는 자석 방식
- **볼펜 (2색: 빨강·파랑)** — 자유 필기(동그라미·메모용)
- **지우개 / 되돌리기(undo)**
- 도구를 클릭하면 활성화, 같은 도구를 다시 클릭하면 비활성화
- **모바일 제스처** — 필기 활성 상태에서 한 손가락은 필기, 두 손가락은 스크롤
- 본문 내 **📌 용어 박스** — 기준금리·HBM·환헤지 등 핵심 용어를 눈높이로 설명 (입문자 배려)
- **완독 도장** — 기사 제목 위에 도장이 찍히는 애니메이션, 마이페이지·홈에 기록 반영
- 필기 내용은 기사별로 자동 저장(localStorage) → 다시 열어도 유지

### 3-3. ✨ AI 하이라이트 요약
- 형광펜으로 그은 문장의 **실제 텍스트를 캡처**해 저장
- 리더 상단바 **✨요약** 버튼 → 바텀시트로 정리 결과 표시
  - 리드 요약문 + 핵심 문장 불릿 + 핵심 키워드 칩
- ※ 현재는 API 없이 브라우저에서 도는 **로컬 추출 요약**(한글 조사·어미 제거 휴리스틱). 실제 Claude API로 교체 가능한 구조.

### 3-4. SNS 내보내기
- 필기한 지면 전체를 인증 이미지로 변환
  - "오늘의 경제공부 · 한경페이퍼" 프레임 + 날짜 + 해시태그(#한경페이퍼 #경제공부 #신문스크랩)
  - 필기·완독 도장·접힌 모서리까지 그대로 포함
- 모바일: 공유 시트(Web Share API), 데스크톱: PNG 저장
- 구현: 지면 DOM → SVG `foreignObject` 스냅샷 → Canvas 합성 → PNG

### 3-5. 마이페이지
- **학습 스탯** — 완독한 기사 수 / 공부한 날 수
- **관심 분야 대시보드** — 완독 기사의 카테고리별 완독 비중을 색상 막대그래프로 시각화
  - 분야별 색상, 건수·비율, "가장 관심있게 보는 분야" 한 줄 요약
- **완독 히스토리** — 최신순 기록(카테고리 태그 포함), 4건 초과 시 "펼쳐보기" 토글
  - 기록을 탭하면 해당 기사가 필기·도장 그대로 다시 열림

### 3-6. 게임 — 경제 퀴즈
- **완독한 기사에서만** 문제가 출제됨 (읽은 내용 복습)
- 기사당 2문항, 지면 내용·용어박스 기반
- **인트로** — 문제 수 / 읽은 기사의 카테고리 칩 / 🏆 최고 기록
- **문항 카드** — 진행바, 카테고리 태그, 4지선다(A~D), 매회 문제·보기 순서 랜덤
- **즉시 피드백** — 정답(초록)/오답(빨강) 표시 + 해설 + 출처 기사
- **결과** — 점수 / 성취 메시지 / 막대바 / 다시 풀기·지면으로
- 최고 기록은 localStorage 저장
- 완독 기사가 없으면 안내 문구 표시

## 4. 데이터 저장 (localStorage)

| 키 | 내용 |
|---|---|
| `hkpaper:done` | 완독 기사 목록(id·제목·날짜·카테고리) |
| `hkpaper:ink:<기사id>` | 기사별 필기 데이터(형광펜 스냅 영역+텍스트, 볼펜 획) |
| `hkpaper:quizBest` | 퀴즈 최고 기록 |

모든 상태는 브라우저 로컬에 저장되어 앱을 껐다 켜도 유지됨. 서버·백엔드 없음.

## 5. 기술 스택 & 실행

- **단일 파일** `index.html` — 프레임워크·빌드·의존성 없음(바닐라 HTML/CSS/JS)
- 신문 감성: 명조 계열 serif, 크림색 종이 배경, 괘선·2단 조판
- 필기: HTML Canvas + Pointer Events(멀티터치), 형광펜은 `caretRangeFromPoint`로 텍스트 줄 스냅
- 대상 뷰포트: 모바일(최대 폭 430px)

### 실행 방법
```bash
npx serve        # 프로젝트 폴더에서 실행 후 브라우저로 접속
```
또는 `index.html`을 브라우저에서 바로 열기.
