## 2. 추진배경 — 현황과 문제점

| 대상 | 현황 | 문제점 |
| --- | --- | --- |
| 산업 전반 (한국경제신문 등 국내 경제·저널리즘 매체) | 네이버·구글 등을 통한 유입 트래픽 감소, SNS·AI 중심 뉴스 소비로 행태 전환 중 | 종이 신문 중심 사용자 경험이 디지털로 전환되는 과정에서 품질·효율이 떨어지는 문제가 고질적 |
| 정보탐색형 고객 (기존 경제 신문 열독자) | 수험생처럼 매일 밑줄을 긋고 메모하며 어려운 경제 콘텐츠를 학습 | 모바일 환경에서는 이러한 열독 행위(하이라이트·메모)를 재현할 수단이 없고, 학습을 루틴화하는 기능도 부재 |
| 경제 뉴스 입문 독자 | 신뢰감 높은 한국경제신문 콘텐츠로 경제 공부를 시작하고 싶어하는 수요 존재 | 지면·디지털 저널리즘의 문법에 익숙하지 않고 경제 분야 전문 지식도 부족해 진입장벽이 큼 |

**핵심 원인**: 지면 위주였던 매체 플랫폼의 특성이 디지털 환경으로 제대로 전환되지 못했기 때문.

**목표**: 전통 저널리즘이 쌓아온 신뢰감 있고 수준 높은 경제 콘텐츠 경험을 디지털, 특히 모바일 웹 환경으로 이어가며 AI 시대에 맞게 혁신하는 것.

## 3. 목표 및 개발 내용

| 구분 | 내용 |
| --- | --- |
| 레이아웃·가독성 | 전통적인 경제 뉴스 콘텐츠의 레이아웃·서체가 주는 신뢰감과 몰입감을 유지하면서도, 모바일 디바이스에 최적화된 레이아웃과 AI 열독 지원 기능을 개발 |
| 개발방향 1 (정보탐색형 고객) | 기사 본문을 드래그하면 종이에 하듯 형광펜 하이라이트·밑줄을 표시, AI가 하이라이트한 문장을 자동으로 요약·액션아이템으로 정리해 노트 형태로 내보냄. 하이라이트·완독 기록은 SNS 공유용 카드 이미지로 자동 생성되어 학습 인증과 루틴화를 유도하며, 개인의 콘텐츠 재생산과 배포도 독려 |
| 개발방향 2 (입문자) | 쉬운 기사 콘텐츠 제작을 자동화하고, 게임형 콘텐츠로 경제 개념을 쉽게 접하도록 하여 진입장벽을 낮춤 |
| SNS 연계 | 하이라이트·완독 기록을 Threads·X·Instagram 등 SNS로 공유하도록 연결해 신규 독자 유입 경로 확장 |
| 개발 플랫폼 | 설치 없이 바로 접근 가능하도록 모바일 웹을 우선으로 하되, 추후 필요 시 앱으로 확장 가능한 구조로 설계 |

**참가과제와의 연계**: AI가 열독 중인 독자의 경제 저널리즘 콘텐츠 소비를 고도화하고 게임형 콘텐츠 제작까지 자동화함으로써, 기존 열독자의 학습 역량과 신규 입문 독자의 경제 리터러시를 함께 향상시켜 인간의 역량을 확장하는 서비스.

## 4. 주요 특징 및 핵심 기술

**컨셉**: "전통 경제 뉴스의 종이신문이 주던 한눈에 하루의 뉴스를 파악하는 몰입감을 디지털에서 되살려 인간의 학습 역량을 확장한다" — 정보탐색형 고객에게는 종이에 하던 학습 행위(하이라이트·메모)를 그대로 재현해주고, 입문자에게는 게임화 콘텐츠로 진입장벽을 낮춰주는 것이 주요 특징.

미디어 특유의 전통 있는 신뢰감 있는 디자인 퀄리티를 유지하면서 모바일 환경과 AI 적용을 최적화하고, 형광펜 하이라이트·밑줄 인터랙션과 AI 에이전트 기술 기반의 액션아이템 자동화 워크플로우로 효율 높은 열독 및 학습 경험을 제공한다. 하이라이트·완독 기록은 SNS 공유가 편리한 카드 형태로 자동 변환되어 학습 인증·생활 루틴화를 유도하고, 인터랙티브 게임형 콘텐츠 등으로 입문자의 진입장벽을 낮춘다.

### 핵심 기술 스택

| 기술 | 적용 영역 |
| --- | --- |
| LLM 기반 요약 & 인터랙티브 RAG 챗봇 | 하이라이트 → 액션아이템 자동 요약, 학습 Q&A |
| 생성형 이미지 기술 | SNS 공유 카드, 게임형 콘텐츠 비주얼 생성 |
| 생성형 보이스 제작 기술 | 게임형 콘텐츠 음성 내레이션 |
| 데이터 시각화 기술 | 학습 기록·완독 데이터 시각화 |
| 대체데이터 활용 기술 | 경제 콘텐츠 분석·인사이트 보강 |
